# GPT · AI 项目工作台

这是一个由用户提出目标、ChatGPT 协助规划、Codex 负责开发的多项目仓库。

## 工作方式

1. 用户手动发送「启动 GPT 项目开发流程」。
2. Chat 先查看本仓库的 `PROJECTS.md`、`AGENTS.md` 和已有项目，判断是完善旧项目还是规划新项目。
3. Chat 给出价值判断、范围、验收标准与可直接交给 Codex 的任务说明。
4. 用户确认后，在 Codex 中启动开发；Codex 在独立分支完成实现、测试与文档，并提交 PR（如环境支持）。
5. 用户验收；Chat 可协助检查代码与 PR。确认后合并，并更新 `PROJECTS.md`。

**注意：** 当前流程是手动触发的；Chat 不会自动启动 Codex，也不会在后台持续开发。不要为消耗额度而制造无用项目。

## 仓库布局（按需建立）

```text
GPT/
├── README.md
├── AGENTS.md
├── PROJECTS.md
├── projects/       # 可独立运行的项目，每个项目一个子目录
├── experiments/    # 验证想法的原型
└── docs/           # 跨项目的设计与研究记录
```

空目录不必预先创建；首个项目启动时再落地。

## 原则

- 实用价值优先，尽量避免重复造轮子。
- 每个项目有明确用途、运行方式和验收标准。
- 不提交密钥、个人敏感信息或未经授权的第三方数据。
- 这是**公开仓库**，提交前检查内容是否适合公开。
- 重要设计与进度写入仓库，不依赖聊天记忆。
