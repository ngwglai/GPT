## 真实 B站读取结果与阻塞

开发环境直接请求 B站时，搜索、WBI 视频详情、公开用户卡片、主评论、楼中楼和无字幕播放器响应存在成功结果；旧详情接口曾返回 412。未向仓库提交上游原始数据或第三方字幕/评论正文。

线上 Worker 的公开读取目前被 B站返回 **HTTP 412**：搜索、视频详情、字幕前置详情、用户资料、用户投稿前置 WBI 信息、主评论均得到 `RISK_CONTROL`。因此线上冒烟脚本返回非零，不能把部署成功视作读取成功。楼中楼的线上完整调用因未能取得前置评论结果而未完成；直接出站诊断同样遇到 412。

排查中有限次尝试了旧/新公开接口、完整浏览器 User-Agent / Referer，以及另两个公开 API 域名；相同 Worker 出口仍返回 412。备用域名没有加入生产 Cookie 发送范围。临时诊断 Worker 已清理，不是项目运行依赖。

本地开发服务的官方客户端完整冒烟同样验证了初始化和工具发现，但本地 workerd 出站遇到超时/网络错误；开发环境直接 HTTP 请求的成功不能替代该端到端测试。

在平台返回风控时应停止高频重试。可行的后续是：使用有效登录会话低频验证登录接口与受限读取；等待风控解除后低频重测；若 Cloudflare 出口持续受限，需由用户决定是否采用自己控制的可访问网络出口。当前未新增代理、数据库或后台，不承诺 Cookie 能解除 IP 风控，不绕过验证码或账号限制。
