# EntropyLab 1.1

面向学生、自学者和复杂系统爱好者的浏览器计算物理实验室。React + TypeScript + Vite；Canvas 2D 实时渲染。四个实验均可独立操作，数学模型完全在本地运行，无后端、账号、数据库、外部 API 或远程字体。安装依赖需要网络，构建后的应用不需要网络请求。

## 本地运行

需要 Node.js 22.12+（推荐 Node 22 LTS）与 npm；Windows PowerShell、cmd、macOS、Linux 均可使用相同命令：

```sh
cd projects/entropylab
npm ci
npm run dev
```

打开终端显示的地址，默认是 `http://127.0.0.1:5173/GPT/entropylab/`。

```sh
npm run lint
npm run typecheck
npm test
npm run build
npm run preview
```

生产预览默认 `http://127.0.0.1:4173/GPT/entropylab/`。构建输出 `dist/`，需通过 HTTP 服务，不支持直接双击 `index.html`。第一次执行浏览器测试前安装 Chromium：

```sh
npx playwright install chromium
npm run test:e2e
```

Linux 若缺少浏览器系统依赖，可使用 `npx playwright install --with-deps chromium`。可通过环境变量 `CHROMIUM_PATH` 指定已安装的 Chromium（CI 默认使用 Playwright 浏览器）。浏览器测试针对生产构建，自动启动预览；4173 端口须空闲。

- 各实验初始暂停；开始/暂停、单步、按当前参数重置、恢复所有默认参数。
- 全局播放倍率 0.25×–4×；除扩散外可调每秒离散更新数。速率是目标，设备繁忙时可以降低；固定步进不会因帧率降低而扩大数值步长。
- 改变粒子数量、硬盘半径/初始速度/碰撞模式、随机游走步长、网格大小、预设或伊辛初态会重置并暂停；显示模式与隔板实时更新，不重置历史。切换实验重置至该实验默认状态，不暗中保留旧任务。
- 重置固定种子 42，方便比较参数；随机模型在相同初态和操作序列下可复现。物理模拟与 Canvas 像素尺寸无关。
- 生命游戏暂停后编辑：左键/触屏拖动绘制，右键或擦除按钮擦除；快速拖动插值补全；边界外输入忽略。编辑保留代数，清空会暂停；重置重新载入当前预设。
- 深浅主题偏好保存在浏览器；存储被禁用时仍可使用。窄屏将导航和参数面板重新排列。

## 数学正确性与解释边界

**硬盘气体与 CCD：**粒子具有 `(x,y,vx,vy,r,m)`，UI 默认同半径、同质量 `m₀=1`，核心支持不同半径与质量。无长程力、无转动自由度。仅当接触且相互靠近时响应：`n=(x₂−x₁)/|x₂−x₁|`、`vrel=v₂−v₁`，冲量 `J=−2(vrel·n)/(1/m₁+1/m₂)`；给两粒子施加等大反向冲量。切向速度不变，单次碰撞守恒向量动量和动能，演化期间没有随机改向或能量归一化。

每个固定步长内，用相对运动二次方程求首次接触时刻（使用避免相消的根），处理事件后推进剩余时间。事件包括粒子接触、墙壁/隔板碰撞和**跨网格**；不是只判断帧末距离。网格宽度不小于最大接触距离，仅检查当前网格及八邻格；跨格事件更新候选，防止初始远离的高速粒子漏检。版本号使速度改变前的预测失效，优先队列按时间处理。墙壁中心接触位置为 `r`/`1−r`，隔板为 `0.5±r`，只反射法向速度。

多体同时接触按确定顺序施加成对弹性冲量，是多接触动力学的近似，并不声称解的唯一性；每次冲量仍守恒。几何容差 `1e−10 L`，时间近同时判断 `1e−12 s`。核心构造器校验半径/质量/有限速度等输入，运行中修改半径或质量须重建求解器；直接调用 `step` 时较长时间须拆为不超过 1 秒的小步，应用固定为 1/60 秒。单步最多弹出 50,000 个事件（含失效事件），队列容量和初态修正迭代均有上限；超限**停止在已处理的物理时间**并要求重置，不穿透剩余时间，也不通过降精度强行追赶。

**初态、隔板与模式：**采用打乱的左半区抖动网格，无重叠且距墙壁和隔板至少一个半径。速度的两个分量从均匀分布采样，去除质心漂移后将 RMS 速率设为滑块值；这是非平衡初态，不是预设的 Maxwell-Boltzmann 平衡分布。速度仅在初始化时设置。半径范围 `0.002–min(0.02,√(0.15/(πN))) L`，保证左半区初始占比最多 30%，增加数量时自动收紧半径上限。

重新关闭隔板保留两侧粒子，以各自最近一侧确定归属，将跨越隔板的圆盘推至允许区域，并做最多 128 轮质量加权局部去重叠/边界投影。该用户操作允许位置修正，反射朝向隔板的速度；不增减粒子、不随机改速、不改变总动能。它不是一块真实运动的隔板，不模拟其插入过程的机械做功。若局部过拥挤无法收敛，完整回退位置、速度、外部冲量，保持隔板开启并提示。数值初态的重合位置也采用确定性去重叠，无法恢复时停止。关闭粒子间碰撞后，粒子允许彼此穿过，但仍有半径和墙壁反射；重新开启碰撞会按种子重置，避免从对照模式的重叠态继续。

**统计解释：**碰撞频率是累计粒子间实际冲量次数除以模拟时间，属于自初态起的时间平均；不含墙壁反射。显示平均速率、总动能 `K=Σmv²/2`、总动量大小及相对能量误差。质量与长度采用模型单位 `m₀` 和 `L`，不擅自标为 SI 焦耳；粒子间碰撞保持动量，但封闭反射容器会受到墙壁/隔板的外部冲量，应验证 `P(t)−P(0)=Iwall`，不能要求总粒子动量恒定。速度直方图使用 16 个固定区间，横轴上限为三倍初始 RMS（零速时为 0.01 L/s），末箱含溢出尾部；没有绘制假定已平衡的理论分布。

空间熵继续使用 10×10 网格粒子占比 `pᵢ`，`H=−Σpᵢlog₂pᵢ`，单位 bit，零概率项贡献为零，上限约 6.644 bit。它是位置的粗粒化 Shannon 熵，**不是完整热力学熵**，不保证严格单调。墙壁反射系统的模拟秒是该模型的时间单位，与伊辛的 Monte Carlo sweep 有本质区别。

**随机游走：**每步方向独立各向同性，`E[|rₙ|²] = nℓ²`。样本均方位移始终相对初始原点计算；轨迹截断不影响统计。步数与任意长度单位 u 不对应真实秒或米，有限样本偏离理论是正常现象。

**生命游戏：**有限边界外视为死细胞；周期边界在两个方向环绕；更新使用新数组，避免就地更新改变规则。没有真实物理时间含义。

**伊辛：**`E = −Σ⟨i,j⟩ sᵢsⱼ`，每条键只算一次；翻转能差 `ΔE = 2sᵢ Σ邻居 sⱼ`。`ΔE≤0` 必接受；其余概率 `exp(−ΔE/T)`。零温明确拒绝升能翻转，不除以零。显示带符号每自旋磁化 `m`、有序指标 `|m|` 和当前空间平均能量 `E/N²`；这些**不是烧入后热平衡时间平均**。无限格临界温度约 2.269；有限尺寸使转变变宽，临界附近需较长弛豫；温度变化不清除历史，便于观察非平衡响应。Monte Carlo sweep **不是实际物理时间**，高温有序初始化也需先弛豫。

## 工程与测试

```text
src/experiments/*/model.ts  纯数值算法，可注入随机源
src/experiments/diffusion/gas.ts / heap.ts  CCD、网格、弹性冲量、有界事件堆
src/experiments/diffusion/worker.ts        纯计算 Worker、可转移缓冲区
src/experiments/session.ts  参数校验、实验状态、有界统计历史
src/experiments/render.ts   Canvas 绘制与坐标映射
src/utils/clock.ts          暂停/恢复/单步与固定步进时钟
src/hooks/useSimulation.ts  React、requestAnimationFrame、ResizeObserver
src/components/             参数面板与有单位的 SVG 图表
tests/models.test.ts        数值、边界、极值、时钟与可复现性测试
tests/gas.test.ts          碰撞、守恒、高速、密度、隔板事务测试
tests/app.test.tsx          页面组件及控制流程
tests/browser/             生产构建 Chromium 操作和布局测试
```

v1.1 未新增依赖。依赖沿用仓库 React 19.1 / TypeScript 5.8 / Vite 6.4 版本，独立锁文件；新增 Vitest、ESLint 和测试依赖，不修改其他项目工具链。轨迹每粒子最多 128 点，统计历史最多 360 点（超过后滚动显示），UI 统计约 10 Hz 刷新，Canvas 使用 requestAnimationFrame 和最高 2× 像素密度。隐藏标签页不再请求推进（已在途的气体批次可完成），恢复后丢弃后台积压；其他三实验单帧最多推进 24 步。气体每个 Worker 批次最多 4 个固定步长，最多一个推进批次在途，缓冲区转移后回收复用，事件堆和网格使用可复用的类型数组，不在每个事件中创建对象。

气体计算由 Web Worker 负责，其他三个实验保持原实现。暂停等待 Worker 确认最后一批状态；重置/切换实验终止旧 Worker，主题切换保留状态。不支持 Worker 时同步回退、每帧最多推进一个气体步长，建议降低数量。计算繁忙时减少实际推进量，不扩大 dt、不跳过碰撞、不假装已达到播放倍率。低性能设备建议降低粒子/网格规模或速率；不声称任意设备均能达到 60 fps。所有算法参数都有有限范围，NaN/Infinity 回退默认，计数取整数。无持久化实验存档、平衡态估计、误差条或数据导出；这些不影响当前交互实验目标。

GitHub Actions 的 `EntropyLab` 独立工作流在 Linux/Windows 执行锁文件安装、ESLint、Vitest、TypeScript 与生产构建；Linux 额外执行 Chromium。现有 RepoScope/ConstraintLab CI 不变。具体已执行结果见 [VALIDATION.md](VALIDATION.md)，配置存在不等于 CI 已通过。性能基准与数值误差见 [PERFORMANCE.md](PERFORMANCE.md)。
