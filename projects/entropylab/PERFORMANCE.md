# 硬盘气体性能与数值误差

日期：2026-10-16。Linux 云环境、Node.js 24.19.0、Chromium 154.0.8037.57。这些是本环境的测量，不是不同设备的帧率承诺。性能会受 JIT、系统负载、GC、浏览器传输和绘图成本影响。

## 可复现命令

```sh
cd projects/entropylab
npm ci
npm run bench
npm run build
# 首次使用：npx playwright install chromium
npm run bench:browser
```

浏览器基准自动启动并停止 4180 端口的生产预览；该端口须空闲。可通过 `CHROMIUM_PATH` 指定系统 Chromium。计算基准已加入 EntropyLab 的 Linux CI；浏览器基准是独立观测命令，不设不稳定的 FPS 门槛。基准使用当前生产模型，没有为性能测试替换成简化物理。

## 纯计算吞吐量

固定 `dt=1/60 s`，保持隔板关闭。每个配置使用种子 42、43、44，分别预热 30 步、计时 180 步，共 540 个计时样本；末态误差包含每次预热后的整个 3.5 模拟秒。`default` 半径 0.004 L、初始 RMS 0.25 L/s；`dense` 为数量对应的半径上限、RMS 0.25；`dense-fast` 为半径上限、RMS 1。无重叠初始化、CCD、跨网格、墙壁反射全部启用。

“吞吐”是累计模拟秒 / 计算耗时秒，不包括 Worker 通信、React、Canvas 或屏幕呈现，**不能换算成浏览器 FPS**。计时后独立进行全粒子对重叠诊断，该正确性诊断不计入模拟耗时；生产求解器不执行这种全粒子对遍历。

| 100 | default | 0.004 | 0.039 | 0.134 | 0.511 | 265.95 |
| 100 | dense | 0.02 | 0.026 | 0.049 | 0.293 | 558.92 |
| 100 | dense-fast | 0.02 | 0.053 | 0.168 | 0.429 | 222.87 |
| 500 | default | 0.004 | 0.161 | 0.244 | 0.765 | 90.97 |
| 500 | dense | 0.009772 | 0.200 | 0.267 | 0.633 | 78.62 |

| 1000 | default | 0.004 | 0.384 | 0.490 | 0.966 | 41.73 |
| 1000 | dense | 0.00691 | 0.527 | 0.720 | 2.253 | 30.09 |
| 1000 | dense-fast | 0.00691 | 1.855 | 2.173 | 2.922 | 8.83 |

## 浏览器调度与实际推进

生产构建、1440×1120 视口，除最后一组 4× 外均为 1× 播放，每组运行预热 0.5 秒，再观察 2.5 秒。与计算基准分开执行，不同时跑 E2E 或另一组计算负载。此表的“RAF/s”是浏览器动画回调频率、P95 是回调间隔，是渲染调度的观测信号，**不是 GPU 实际呈现帧数**；模拟推进率来自实际收到的 Worker 状态。

浏览器 `dense-fast` 使用滑块能到达的最大 0.0001 L 格点半径（向下取整），因此与计算基准精确半径上限有细微区别。最后一个 Worker 批次时间是单点观测，包含状态统计与缓冲打包，不能代替计算中位数。

| 粒子数 | 场景 | 目标倍率 | 观测 RAF/s | P95 间隔 ms | 实际模拟s/墙钟s | 最后 Worker 批次 ms |
| --- | --- | --- | --- | --- | --- | --- |
| 100 | default | 1× | 60.0 | 16.7 | 0.99 | 0.100 |
| 100 | dense-fast | 1× | 60.1 | 16.8 | 0.99 | 0.200 |
| 500 | default | 1× | 60.1 | 16.7 | 0.99 | 0.300 |
| 500 | dense-fast | 1× | 60.3 | 16.8 | 1.00 | 0.700 |
| 1000 | default | 1× | 60.4 | 16.7 | 1.00 | 0.600 |
| 1000 | dense-fast | 1× | 60.3 | 16.8 | 1.00 | 1.900 |
| 2000 | default | 1× | 60.1 | 16.8 | 0.99 | 1.800 |
| 2000 | dense-fast | 1× | 60.4 | 16.8 | 1.00 | 6.900 |
| 2000 | dense-fast | 4× | 60.3 | 16.7 | 1.24 | 19.600 |

默认选择 500 粒子，保留 2,000 上限：本环境在 1× 的观察窗口中接近目标推进率，最大密度与高速的计算成本仍明显较高；最后一组 4× 展示了目标播放倍率和实际推进率的差别。不能据某一组接近 60 的 RAF 观测宣称全设备 60 FPS。慢设备/高倍率还会进一步降低推进；界面明确说明“计算繁忙时放慢模拟”。Worker 每次最多 4 个固定步长，推进请求不积压；超事件预算则暂停。优先保持碰撞正确性，不以穿透换取播放倍率。

## 数值误差与适用边界

- 12 组 × 3 个种子的最大末态相对能量误差 `|K/K₀−1|` 为 `3.109e-15`。
- 扣除墙壁/隔板累计外部冲量后，最大末态向量动量残差为 `1.518e-13 m₀L/s`。粒子总动量本身不恒定，不把壁面冲量错判为碰撞不守恒。
- 独立全粒子对末态检查的最大正重叠量为 `0.000e+00 L`；这不是数学上所有时刻的零误差证明。单元测试另在高密度演化中抽查，允许几何容差 `1e−10 L`。
- 长期单元测试运行 100 粒子 20 模拟秒，检查粒子数、相对能量误差 `<1e−10`、外部冲量补偿后的动量分量误差约束 `1e−9`；另有高速、三体同时接触、零速、微小相对速率、重合中心和完整/半步一致性测试。
- 近同时多体接触按确定顺序近似成对响应；不是对稠密刚体接触网络的唯一精确解。时间近同时容差 `1e−12 s`，单步 50,000 个事件，几何修正最多 128 轮；预算失败不跳过余下物理时间。
- 重新关闭隔板是保动能的位置修正操作，不是完整移动壁面做功过程；局部过密时可能拒绝关闭并回退。没有吸引力、转动或热浴；没有把速度分布假定为已经达到热平衡。
- 本机测试不代替原生用户电脑、Safari/Firefox、移动设备的性能验收。无后台服务、远程计算或新增依赖。
