# 模型、算法与实验语义

## 模块

`model.py` 严格解析与搜索侧约束求值；`validation.py` 独立实现完整赋值语义；`solver.py` 搜索、传播、启发式及有界快照；`problems.py` 实例构造；`benchmarks.py` 重复实验和导出；`api.py` 本机服务和异步任务；`cli.py` 命令行。前端只消费 JSON API，不实现求解。

## 声明格式

```json
{
  "name": "Example",
  "variables": {"x": [1, 2, 3], "y": [1, 2, 3]},
  "constraints": [
    {"type": "compare", "vars": ["x", "y"], "op": "lt"},
    {"type": "sum", "vars": ["x", "y"], "op": "eq", "value": 4}
  ],
  "metadata": {}
}
```

- `compare`: 一个变量与整数 `value` 比较，或两个变量比较（此时不带 value）；操作为 `eq/ne/lt/le/gt/ge`。
- `sum`: `vars` 之和与 value 比较，空和为 0；每个变量只可出现一次。
- `all_different`: vars 两两不同；空集与单元素恒真。
- `table`: `allowed` 为允许的整数元组数组；完整值按 vars 顺序匹配。
- `and/or`: `constraints` 子约束数组；空 AND 为真，空 OR 为假。最大嵌套深度 8。
- `queens`: 内置扩展，两变量列号不同且差的绝对值不等于正整数 `distance`。
- 变量名唯一，约束引用必须存在且不重复；域可空（代表无解），域内整数不重复。整数绝对值 ≤1,000,000，常量绝对值 ≤150,000,000。未知模型/约束字段拒绝。
- metadata 仅供展示（kind、size、edges、courses、slots），不参与约束语义。用户导入文件不执行任何代码。

## 搜索与传播

所有算法启动时做一元过滤。BT 使用深度优先回溯，赋值后只检查已完全赋值的约束，不进行前向传播。FC 在赋值后逐个试验未赋值变量的值，对其他变量已赋值的约束做过滤；同时使用 Sum 边界过滤。

MAC 先执行 FC，再构建所有二元约束的双向弧队列。每条 `(x,y)` 弧中，对 x 的每个值检查 y 域是否存在同时满足该变量对所有二元约束的支持；无支持则删除。x 域变化后将其他 `(z,x)` 入队，空域立即失败。AC-3 与 Sum 过滤反复执行至共同固定点。每个搜索节点重新建队列，便于审计；此处仍有优化空间。

AllDifferent 展开为二元不等；AND 可展开。其他未专门实现的高元/OR 约束采用正确但较弱的 FC 和完整赋值检查。不能将它们称为完整广义弧一致性。

Sum 对每个候选值，计算其他变量的最小和/最大和。等式只保留目标处于区间内的值；不等式按必要边界条件过滤；不等仅在上下界同时等于目标时删除。因此非连续域可能保留无支持值，但不会删除真正有解的值。

每个分支复制所有域，失败后丢弃子副本，不修改父域或输入模型。输出解通过独立 `validation.valid` 再验证。参考枚举直接对域笛卡尔积运行该独立验证器，不调用搜索/传播/展开代码。

## 启发式

- fixed：JSON 变量插入顺序；MRV：最小当前域；Degree：最多未赋值邻居；Dom/Ddeg：域大小除以未赋值邻居数（零用 1）。平局按变量插入顺序。
- natural：原始域顺序；random：每次 solve 新建指定种子的 RNG；LCV：试赋当前值后对未赋值邻居的值统计已能求值约束的失败数，较小者先试。弱传播意味着它是影响估计，不保证全局最优。

## 结果

`status`: 有至少一个解为 SAT；搜索穷尽且无解为 UNSAT；无解且资源/取消停止为 UNKNOWN；输入或校验错误为 ERROR。`complete` 只在搜索穷尽时为 true，达到最大解数即停止，保守报告 false，即使该解碰巧是最后一个。SAT 也可能因超时、节点上限或取消而枚举未完。

`reason`: exhausted / solution_limit / timeout / node_limit / cancelled。超时使用单调时钟，属于合作式限额，频繁在搜索、约束检查、弧处理处检查；模型解析和单次原子操作不会被中断。节点上限只限制试赋值次数，不限制初始传播。

## 统计定义

| 字段 | 精确定义 |
| --- | --- |
| seconds | solve 入口至结果构造前的单调时钟时间；包含模型解析、传播、启发式、验证及启用的轨迹；不含 HTTP/序列化/渲染 |
| nodes | 实际尝试的变量-值分支数，根不计 |
| backtracks | 试赋分支返回父状态的次数，包括找到解后继续枚举的返回；限额打断未返回的不计 |
| constraint_checks | 搜索侧完整约束求值调用次数，包括传播/LCV；不含独立最终验证；组合约束算一次外层调用 |
| propagations | FC 遍历次数 + AC-3 弧处理次数 + Sum 单变量过滤次数；是一种明确定义的工作项计数，不是约束检查数 |
| deleted_values | 过滤器删除的域候选值累计数；不含分支赋值本身的域缩小；不同分支重复删除分别计数 |
| max_depth | 进入递归搜索的最大已赋值变量数；传播直接拒绝的分支可能只出现在轨迹中 |
| solutions | 当前已发现解数，只有 complete=true 才是全部解数 |
| peak_memory_bytes | null；当前没有可靠的每任务隔离测量，不用进程 RSS 冒充核心求解峰值 |

## 轨迹与资源

事件包括 SELECT_VARIABLE、TRY_VALUE、DOMAIN_REDUCED、CONSTRAINT_FAILED、BACKTRACK、SOLUTION_FOUND、SEARCH_COMPLETED。每条保存独立 assignment、domains、depth 快照，故可前后随机访问；事件深度为对应快照赋值数，根为 0。终止事件可因截断而缺失。

事件数最大 10,000、估算序列化数据预算 8 MB，达到任一阈值停止追加，返回 trace_truncated=true。预算是估算而非 Python 对象堆精确测量；仍有严格事件数/模型尺寸上限。实验关闭轨迹以公平计时。最大解数 10,000、节点 10,000,000、每次 120 秒；API 请求体最大 1 MB，变量 150，约束 12,000。求解器在展开 AllDifferent 前计算扩展规模，最多允许 20,000 条展开约束；超过预算返回 ERROR，不分配海量中间对象。展开前与展开期间都检查超时和取消。最多八个保留任务，每次只接受一个活动任务，旧结果被逐出时导出会返回 404。

API 绑定 127.0.0.1，检查 Host/Origin；不支持公网部署或多用户鉴权。实验最多 8 个实例、12 组配置、10 次重复，可随时取消。实验 JSON 返回按 SHA-256 `problem_id` 索引的 `problems` 字典和只引用 ID 的 `rows` 数组；避免按配置与重复次数反复嵌入大问题。CSV 的 `problem` 单元格仅在该 ID 第一次出现时包含 JSON，后续行留空；配置和环境每行均为 JSON 单元格。问题 ID 是规范 JSON 的 SHA-256，包含 metadata。种子从实验 seed 起按重复编号递增，每组配置相同。绘图展示所有重复的原始观测，包括未完成状态，绝不将超时伪造为零。
