# CompilerLab v0.1 语言规范

本规范先于实现编写。源代码只进入本地受限 DSL，不作为 JavaScript 执行。

```ebnf
program = statement* EOF ;
statement = "let" IDENT ":" type "=" expression ";"
          | IDENT "=" expression ";"
          | "print" "(" expression ")" ";"
          | "if" "(" expression ")" block [ "else" block ] ;
block = "{" statement* "}" ;
type = "int" | "bool" ;
```

表达式支持十进制整数、true/false、变量、括号、一元 -/! 及二元运算。
标识符为 ASCII `[A-Za-z_][A-Za-z0-9_]*`，关键字保留；支持空白与 `//` 行注释。
位置为从 1 开始的行/列，偏移及列按 UTF-16 代码单元计；CRLF 换行一次。

- 优先级从低到高：`||`、`&&`、`== !=`、`< <= > >=`、`+ -`、`* /`、一元 `- !`、主表达式。二元左结合，一元右结合；不支持表达式赋值。
- 算术及有序比较只接受 int；`&& || !` 只接受 bool；相等比较两端必须同型。声明初值和赋值必须严格匹配显式类型；if 条件必须为 bool。无隐式转换。print 接受任一类型，每次追加一行十进制整数或小写布尔值。
- int 为**对称的有符号 31 位幅度**范围 `[-2147483647,2147483647]`。正字面量不得超过上界；负数由一元负号构成。使用精确整数运算，结果超界报 Overflow；除零报 DivisionByZero；整数除法向零截断（`-7 / 2 == -3`）。无环绕、Infinity 或 NaN。
- 二元运算先左后右。`false && rhs`、`true || rhs` 不求值 rhs；其他二元先求值两端再计算。所有分支（包括不可达分支）仍做静态类型检查。
- 声明必须初始化；声明名在初始化表达式之后才进入作用域。同一块内重复声明非法；内层块可遮蔽外层。顶层是一个块，if 的每个分支有独立块。赋值查找最近声明；离开块删除该块变量，对外层变量的修改保留。最终状态仅包含已经成功声明的顶层变量（错误前的修改保留）。变量名（包括 `__proto__`）作为数据键处理。
- 非法字符、语法错误、未声明名、重复声明、类型不匹配及超范围字面量禁止执行。运行时错误含源位置；错误指令不提交栈/变量/输出修改，PC 停在该指令。解释器与 VM 都返回错误前输出和顶层状态。
- 默认限制：源代码 8192 UTF-16 单元、2048 tokens（含 EOF）、512 AST 节点、表达式/块深度 32、128 声明、2048 指令、4096 VM 步、4096 解释器节点求值、256 行输出。编译超限拒绝，执行超限返回 ResourceLimit；VM 每个成功指令及失败尝试产生独立快照，可重放。执行预算是各引擎的操作预算，不要求耗尽时点等同。优化可能减少步骤，等价性适用于未耗尽操作预算的程序，或共同的语言错误；预算终止应单独报告。
- 优化只折叠安全的字面量运算及短路决定的布尔表达式；不把可能求值/报错的左操作数丢弃，不折叠会报错的算术，不删除声明或条件语句。因此输出、语言运行错误类别与顶层状态不变；字节码及指令轨迹可以不同。

不支持独立裸块、循环、函数、数组、对象、字符串、宿主代码、外部文件或网络。AST API 输入须来自 parse/analyze 管线；低层 VM API 仍校验指令、类型、跳转和预算，损坏字节码返回 InvalidBytecode。
