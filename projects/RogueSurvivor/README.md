# 星烬远征 · RogueSurvivor

纯前端的 2D 俯视角动作 Roguelite。自动普通攻击、手动技能、自由移动和闪避，在四张魔法地图中组合武器、迎战首领，完成二十波主线远征（清场快可提前推进），或继续无尽星夜。

采用 TypeScript、Phaser 3、Vite。无账号、无广告、无付费接口、无数据库服务器；运行时不请求外部字体、图片或音频。默认美术为本次内置 image_gen 原创图片，保留程序矢量回退；战斗音乐使用用户提供的六首本地 MP3，音效使用本地CC0采样与Web Audio混音。与仓库中的 Godot 卡牌游戏 RogueLab 是两个独立项目。

## 本地运行

需要 Node.js **22.15+**（推荐最新 Node 22 LTS 或 Node 24）与现代浏览器（电脑、手机和平板）。

```bash
cd projects/RogueSurvivor
npm install
npm run dev
```

浏览器打开终端显示的地址。Windows PowerShell / 命令提示符同样适用。

```bash
npm run build          # 严格 TypeScript 检查 + 生产构建
npm run preview        # 用 HTTP 预览 dist
npm test               # 核心规则、存档与边界单元测试
npx playwright install chromium
npm run test:e2e       # 先构建，后运行生产页面浏览器测试
npx playwright install --with-deps webkit
npm run test:mobile:webkit # WebKit移动视口与Pointer Events模拟，非真机iPhone
npm run simulate      # 三角色 × 三种子，正常伤害的完整战斗模拟
npm run simulate -- --stress  # 星光森林 7201 秒无尽稳定性模拟
npm run simulate:worlds       # 三新地图 × 三角色 × 两种子
npm run simulate:worlds -- --stress # 三新地图各7201秒，含洗牌与存档
npx tsx tools/world-visual.ts # 构建后截图及三地图浏览器压力
```

不支持直接双击 `dist/index.html`，请使用 HTTP 服务。Linux 缺少浏览器系统依赖时执行 `npx playwright install --with-deps chromium`。可通过环境变量 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定已有 Chromium；常规用户无需设置。

## 星火与动态角色

每击败一只正式Boss获得1次星火，初始0，可累积。生命归零先完整播放战败；有星火可选择复活，消耗1次，完整站起后恢复50%生命并获得3秒无敌，清除附近240像素敌弹，保留当前波次和场上敌人。HUD及结算显示星火统计。

三角色七种动作由独立状态机管理。角色选择展示动态待机，资源工坊可按`animation.<角色>.<动作>`替换动作条带；旧静态自定义角色仍优先生效。帧数、来源、重建脚本和预览见[V1.6.md](V1.6.md)。

## 手机与平板操作

默认按触屏输入能力显示左下摇杆与右下原技能栏，设置中可选择自动、始终显示或关闭摇杆。左手拖动摇杆，右手可同时点击 Q／E／R 和闪避。摇杆有16%死区，越过死区后与键盘同速移动；松手、取消触摸、暂停、弹窗、死亡或旋转屏幕时释放输入。

陨火／星落终章自动选择有效敌人，也可轻触战场指定落点；星贯自动瞄准，没目标时沿移动或上次朝向；霜环／星幕／复苏仍以自身为中心。点击“瞄准”提示恢复自动。所有瞄准沿用原450像素施法限制。电脑鼠标瞄准和WASD不变。技能与装备的完整说明可从暂停菜单展开，点击装备图标也可查看。

推荐横屏，竖屏仍可完整游玩。适配安全区域与浏览器可视高度，菜单和卡牌可滚动；不强制锁定方向、不禁用菜单缩放。真机Safari／Chrome体验仍需用户验证，浏览器模拟不等同真机测试。

## 操作

| 操作 | 功能 |
| --- | --- |
| WASD | 八方向移动；斜向速度归一化 |
| 鼠标 | 指向落点或发射方向，技能最远落点为 450 |
| 自动攻击 | 按射程、视线、威胁及目标稳定性自动评分；远程适当优先辅助怪，无需点击 |
| Q | 主动攻击技能：陨火、霜潮、星贯三选一 |
| E | 生存技能：星幕或复苏 |
| R | 星落终章：连环范围攻击并清除敌方弹幕 |
| 空格 | 按移动方向冲刺并获得短暂无敌；静止时沿上次方向 |
| ESC | 暂停 / 恢复；可保存、设置或访问资源工坊 |
| 1 / 2 / 3 | 选择对应升级奖励 |

红色圈为敌方攻击预警，绿色晶体为经验，金色轮廓为精英。角色受击时获得短暂保护；治疗不能超过生命上限。浏览器失去焦点或切到后台时自动暂停。设置中可以关闭震动、调节音量、减少装饰和特效，并显示 FPS 与对象数量。

## 内容与模式

- **3 位角色**：逐星游侠（追星弓）、余烬守卫（弧月刃）、月棘术士（烬火杖）。初始生命、速度、武器与推荐技能各不相同。
- **5 种自动武器**：追星弓、弧月刃、烬火杖、月环、萤火灵。可同时携带全部五种，每种五级。五级分别增加箭矢、扩大斩击、扩大星火爆炸、增加卫星、获得追踪。
- **6 种主动技能**：陨火、霜潮、星贯、星幕、复苏、星落终章。技能精通最多五级，例如三级陨火增加两枚延迟陨火，三级星贯变为三束光矛。
- **70 项卡牌定义**，三档稀有度，基础出现权重 6:3:1，具备前置条件、等级上限与互斥关系。穿林与碎星互斥，可同时持有五种武器，独行之道为少武器构筑提供额外收益；冰火共鸣、野火蔓延、召唤与卫星强化可形成联动。
- **17 类普通敌人**：保留七种原怪物，新增治愈妖精、星光护卫、时空幽灵、分裂史莱姆、魔法镜灵、贪婪宝箱怪、星界召唤师、诅咒魔女、月光蝴蝶、水晶巨蟹，具有独立辅助、位移、反射、召唤、临时干扰与方向防御机制。
- **7 种 Boss**：原三种保留；新增水晶女王、糖果魔女、月蚀圣女和镜中少女，生命低于45%进入强化阶段。
- **标准模式**：第5、10、15、20波按地图首领序列入场，前一首领存活时暂缓下一只；击败地图最终首领通关。一局四个节点，不强制经历全部七种Boss。
- **无尽模式**：所有地图均可直接开始或通关后继续；每五波调度一只首领，逐步出现跨地图镜中少女，环境机制与敌人组合持续运行；原四类世界事件保留。
- **长期成长**：25 级起出现无垠领悟；常规升级耗尽后仍可选择。伤害采用 `1 + 0.23 * log(1 + 层数)` 的成长，并附带回复，不使用指数递归叠加。等级没有玩法层面的固定终点。
- **四张地图**：3600×3600连续空间，星光森林、水晶洞窟、糖果魔女庭院、月蚀遗迹默认开放。开始时在角色选择下方选地图，各有独立美术、障碍布局、敌人权重与Boss序列。
- **环境互动**：破坏水晶触发有限连锁、拾取有提示的六类糖果、在明暗法阵间走位；糖果和敌方诅咒均为有时限状态，不写入永久卡组。
- **音乐**：升级、正负抽卡、洗牌与战斗中查看卡册/图鉴时继续播放，歌曲结束自动接下一首；手动暂停和失焦/隐藏仍暂停，回营地和结算停止。仍可独立关闭音乐、调节音乐与音效音量。

- **纪念解锁**：首领猎人、星林守护者、长夜行者；记录页展示，不提供永久战力加成，三个角色默认可选。

## 存档和恢复

使用 IndexedDB `starfall-survivor`，数据库结构版本仍为1，局内Run结构版本为4，显式迁移原Run版本1、2及3。分别保存 `run`、`backup`、`settings`、`profile`、`assets`。保存波次编号、起始时间、入场进度、Boss序号及等待出场资格，以及玩家、敌人、弹道、领域、地图种子与障碍、随机数状态、计时器、待选奖励及战斗统计，恢复后无需重新抽奖。瞬时飘字与音效不存档。

每 30 秒、升级安全节点、暂停和结算时自动保存；暂停菜单可手动保存。写入按顺序串行执行，每次保留上一份有效存档作为备份。坏存档不会阻止启动，首页提供恢复备份或开启新局。备份也无效时只能开始新局。未知版本拒绝恢复，保留原数据；后续升级应在 `validateRun` 前新增显式迁移函数，不能直接强制转换。

存档、设置与图片只属于当前浏览器和站点来源。清除站点数据、隐私窗口退出、换浏览器或浏览器回收空间会失去数据；本版本没有云同步与存档文件导入导出。新远征替换继续槽位并保留旧备份。死亡和通关会写入终局存档；只有未结束的远征提供继续入口。

## 图片资源替换教程

在主菜单或暂停菜单打开 **资源工坊**。共 **115 个稳定资源 ID**，保留原有角色/敌人/武器/技能ID，新增立绘、头像、卡面、场景与背景；其中114个ID映射生成图片，ui.panel保留可替换的默认面板。精确映射见 ART-ASSETS.md。

1. 在网格中选择资源，查看默认/当前预览。
2. 点击“选择本地图片”，上传 PNG 或 WebP；单张最多 2 MB、最长边 2048 像素。不接受 SVG、脚本或远程 URL。
3. 调整显示缩放（0.1–4 倍）、水平和垂直偏移（±128 像素），点击“应用配置”。这些参数**不改变**碰撞半径、武器射程或伤害范围。
4. 动画使用按行排列的精灵图：填帧宽、帧高、帧数（1–64）和帧率（1–30）。静态图设为一帧；独立序列帧可先拼为精灵图，目前不提供序列图片批量上传器。
5. “恢复默认”只恢复当前条目。“导出资源包”下载 JSON；“导入资源包”验证所有条目后整体替换自定义资源。没有出现在导入包中的条目恢复默认。
6. 总资源包上限 24 MB，解码后总像素上限约 1600 万（建议单张 64–256 像素）。保存失败会显示中文错误。启动时解码或校验失败会回退默认美术，恢复正常游戏。

示例结构（`data` 必须填写实际图片数据；不要原样导入占位符）：

```json
{
  "version": 1,
  "assets": {
    "player.ranger": {
      "data": "data:image/png;base64,<实际图片编码>",
      "scale": 1,
      "x": 0,
      "y": -6,
      "frameWidth": 64,
      "frameHeight": 64,
      "frames": 4,
      "fps": 8
    }
  }
}
```

ID 清单见 `src/services/assets.ts`。角色与敌人使用 `player.*`、`enemy.*`，武器 `weapon.*`，弹道 `projectile.*`，技能 `skill.*`，环境 `map.*`，界面 `ui.*`。技能自定义贴图用于效果/图标，敌方危险圈仍由独立预警绘制，避免贴图遮蔽攻击规则。

默认素材为本项目原创程序绘制，没有外部素材授权依赖。导入你拥有合法使用权限的图片。资源包只作为 JSON 数据解析，不求值脚本，不加载 HTML。

## 架构与扩展

```text
src/
  core/
    types.ts        类型契约与可序列化 Run
    create.ts       新远征、角色属性、种子地图
    math.ts         PRNG、圆形碰撞、空间网格、连续弹道检测
    progression.ts  奖励过滤、加权抽样、构筑与等级
    combat.ts       武器、主动技能、伤害、状态与对象池
    director.ts     敌人 AI、Boss、生成与事件调度
    world.ts        固定步进与生命循环
  data/content.ts   集中管理角色、武器、技能、敌人、升级和预算
  render/
    art.ts          程序矢量美术，只负责外观
    scene.ts        Phaser Canvas 渲染、输入和显示对象池
  services/
    storage.ts      IndexedDB、存档验证、备份与版本入口
    assets.ts       稳定 ID、图片校验、资源包与持久化
    audio.ts        六首MP3与独立音效
    musicPolicy.ts  音乐与逻辑暂停的优先级
  ui/style.css      中文响应式界面
  main.ts           菜单、HUD、控制器与应用生命周期
```

逻辑层不依赖 Phaser / DOM；测试和游戏使用同一套 World。浏览器每秒 60 个固定逻辑步，积压时每帧最多六步，避免长任务回补锁死；极低帧率下会放慢游戏时间，不跳过碰撞。使用 Phaser Canvas 渲染，减少软件 WebGL 环境的启动和驱动开销。

新增内容：先扩展 ID 联合类型与配置，然后在对应独立系统中实现新机制，最后增加资源 ID 和测试。单纯调整伤害、生命、稀有度或生成曲线，只修改 `content.ts`。新地图在 `data/maps.ts` 配置障碍、权重、首领与稳定资源ID，环境机制在 `core/environment.ts` 扩展。新增复杂 Boss 建议提取新的行为模块，避免增长成单一战斗文件。

## 性能边界

150 个敌人（普通生成保留 3 个首领名额）、360 个投射物、64 个领域、180 个经验对象、120 个短暂视觉效果；过多经验合并到最近经验对象，保留总经验。敌人达预算时显示提示并暂缓新增，不删除存活 Boss。屏幕外图像不提交绘制，弹道按生命周期回收；敌人仍继续模拟，不瞬移到玩家身边。子弹逻辑对象和 Phaser 图像/文字对象复用。

碰撞使用空间哈希网格和弹道线段距离，防止高速穿模。高密度战斗自动减少装饰与特效，手动简约模式进一步减少视觉开销，不改变伤害判定。机制升级有界，数值升级无限且采用有效上限/收益转换；分裂弹不再分裂、燃烧扩散由死亡清理阶段处理；统计伤害使用有限上限，长期增长采用对数曲线。所有恢复数据经过有限数、类型、内容 ID、数组长度与结构校验。

Vite 使用相对 `base: './'`，可放在 `/GPT/RogueSurvivor/` 或其他子目录。`.github/workflows/rogue-survivor.yml` 在 Linux / Windows 执行审计、单元测试、构建、完整战斗模拟、两小时压力模拟和生产 E2E，并纳入根 CI required。

**只扩展既有聚合 Pages 工作流**，同时打包已有 `entropylab`、`roguelab` 和新增 `RogueSurvivor`，不会用游戏覆盖整个站点。游戏目录合并到 main 触发自动发布；也可在 Actions 中手动运行 **GitHub Pages**。仓库 Settings → Pages → Source 应为 **GitHub Actions**。若 environment 需要审批，由管理员在对应部署任务处理。

实际发布状态与验证证据见 [VALIDATION.md](VALIDATION.md)。未经成功的 Actions 部署和 HTTP 检查，不把预期 URL 当作已上线地址。

## 已知限制与后续

- 桌面键鼠优先；菜单适配窄屏，但没有触屏战斗摇杆、手柄支持或按键重映射。
- 当前四个地图主题；角色动画为位移、摆动、闪烁与可替换精灵图，没有完整骨骼动画。
- 本地数据不跨设备同步。IndexedDB 被禁用时仍可游玩，但无法保证保存。
- 只有有限组自动玩家模拟，不能代表所有构筑和人类玩家的胜率；真实玩家平衡反馈仍需收集。
- 两小时测试是同一逻辑的加速压力运行，持续无敌用于保证走到后期，不代表普通构筑能无伤生存两小时，也不等于所有浏览器连续运行两小时的内存证明。
- 本地/CI 浏览器验证以 Chromium 为准；Firefox、Safari 和真实移动设备需进一步验证。硬件不同，不能承诺所有设备固定 60 FPS。

验收映射、测试数据与具体结果见 [VALIDATION.md](VALIDATION.md)。

### 战斗背景音乐

使用用户提供的六首MP3，按当前地图歌单自动轮播，最后一首后回到第一首。升级、正负抽卡、命运洗牌、卡册和图鉴期间继续播放；手动暂停及失焦/隐藏时暂停，回主菜单或结算停止。设置提供独立音乐开关和音量滑块（即时预览，点击保存设置后持久化）；旧设置默认开启。浏览器需先点击页面才能播放。音效仍独立控制，音乐加载失败不会阻塞游戏。六首音频只按需加载，不预解码全部文件。

资源位于 `public/audio/battle-1.mp3` 至 `battle-6.mp3`，来自用户本次提供的音乐；不声明额外再分发许可。

## v1.5《波次远征》

每波有固定生成预算，在10～24秒入场窗口内分批生成。全部入场后清场立即推进；普通波55秒、Boss波75秒到时同样推进，旧怪物和首领保留。第5／10／15／20波调度地图首领序列；同屏最多一只，等待出场资格不丢失，最终首领击破通关。无尽模式每五波继续调度。HUD显示波次、倒计时、入场状态和首领预告。

保留真实生存时间和原有生命／伤害／攻击频率成长，组合解锁参考波次或实际时间中的较快进度。不改经验公式、单怪经验、卡牌掉落和经验合并。800敌人／1200弹幕／240区域容量不变；达到容量取消本波尚未入场的普通怪名额，不移除存活单位，首领资格保留。

四地图歌单不同；继续存档时按地图恢复歌单首曲，不保存歌曲秒数。音乐暂停策略保持原样。新增23个CC0采样，覆盖攻击、六技能、拾取、抽卡、波次、首领预警和结算；同类节流、12声部上限，音乐和音效音量独立，音效滑块即时静音。具体参数、歌单、迁移与验证记录见 [V1.5.md](V1.5.md)。
