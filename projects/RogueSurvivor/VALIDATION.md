## 本地结果

- `npm test`：77 项规则、边界与安全回归通过。
- `npm run build`：严格 TypeScript 与 Vite 生产构建通过。主应用约 67 kB，Phaser 分块约 1.2 MB（gzip 约 332 kB）；保留依赖体积警告，没有隐藏。
- `npm run test:e2e`：16 项生产 Chromium 流程通过，包括暂停中动态换图后恢复战斗。
- `npm run simulate`：9 组正常战斗，三种角色均自然通关；脚本通关门槛通过。
- `npm run simulate -- --stress`：7201 秒连续逻辑运行及 12 次完整快照检查通过。
- `npm audit`：完整依赖零已知漏洞。
- 根目录 `python -m unittest discover -s tests -q`：53 项隐私工具回归通过；暂存区隐私扫描无命中。

第一轮 E2E 发现标题换行导致可访问名称中含空格，修正了测试选择器；正常保存、升级、死亡和最终战流程通过。后续取消 Phaser 自带时间平滑、改用固定步进时，晚期首领测试夹具的一级角色会连续升级，原先按固定短等待关闭奖励的断言出现竞争；改用高等级末期夹具，升级队列另有独立测试。初次软件 WebGL 预览帧率偏低，改用 Phaser Canvas，并避免在不透明菜单后重复绘制战场。

初始依赖审计发现旧 Vitest 的安全通告，升级到 Vitest 5.0.5 后完整 npm audit 为零漏洞。保持锁文件并在 CI 使用 npm ci。

## 正常战斗模拟

`npm run simulate` 使用和浏览器相同的战斗逻辑、正常生命和伤害，不跳时间、不强制击杀首领、不赠送经验。自动玩家会选奖励、拾取经验、绕开近身敌人和危险区，并主动施法；每步 0.05 秒（20 Hz），共三角色 × 三固定种子。

第一轮余烬守卫三个种子全部早亡，随后将初始斩击从 34/0.9 秒/125 半径调整为 46/0.78 秒/155 半径。复验结果：

| 角色 | 种子 11 | 种子 29 | 种子 83 |
| --- | --- | --- | --- |
| 逐星游侠 | 130 秒死亡 | 1205 秒通关 | 1216 秒通关 |
| 余烬守卫 | 1220 秒通关 | 250 秒死亡 | 1223 秒通关 |
| 月棘术士 | 1217 秒通关 | 1217 秒通关 | 1241 秒通关 |

这是九组特定自动策略的样本，七组通关，不宣称是玩家总体胜率。脚本要求每个角色至少有一个自然通关种子，否则返回失败。

## 长期压力模拟

`npm run simulate -- --stress`：连续模拟 7201 秒，无时间跳跃，共 144020 个逻辑步。持续无敌只用于避免测试过早结束，武器冷却、敌人、命中、经验、升级、Boss 和事件仍由真实引擎推进。每 600 秒验证一次完整快照，覆盖 60 分钟与 120 分钟。脚本达不到 7200 秒或预算/数值检查失败时返回失败。

最终完整运行记录：343 级、51940 次击杀、23 个已击败首领；峰值 147 个敌人、152 个弹道；12 次快照验证均通过。最终与浏览器测试并行运行用时约 85 秒，Node 堆间隔采样峰值 124 MiB；它不是进程内存上限或浏览器堆的保证，不能直接外推到其他机器。

## 浏览器验证边界

生产页面通过 Playwright 使用真实 Chromium；测试没有注入生产作弊接口。为了验证晚期流程，部分用例通过浏览器 IndexedDB 准备合法战局，再由真实战斗触发击杀、升级或结算。自然通关由独立完整模拟负责；不把准备末期存档的 E2E 冒充二十分钟人类游玩。

两小时稳定性是逻辑加速测试，浏览器另有真实高密度短时渲染检查。真实硬件、Firefox、Safari、长期浏览器内存、用户人工体验与更大样本的平衡测试仍待后续反馈。

## 远端状态

代码通过独立分支 / PR 交付。远端最终结果以 [CI](https://github.com/ngwglai/GPT/actions/workflows/ci.yml) 与 [GitHub Pages](https://github.com/ngwglai/GPT/actions/workflows/pages.yml) 实际运行状态为准（仓库网页可从 Actions 导航打开）。发布入口路径为 `/GPT/RogueSurvivor/`，合并前不宣称已经上线。最终交付回复将提供实际 PR、CI 和已验证地址。

本地截图检查确认中文布局、角色/敌人轮廓、技能 HUD 和高密度战场可用。软件渲染容器的短时密集场景观察约 19–26 FPS，属于该测试环境数据；自动精简特效仍保留敌人、攻击预警和判定，不承诺所有硬件固定 60 FPS。
