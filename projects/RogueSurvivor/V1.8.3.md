# v1.8.3《怪物线性成长与难度平衡》

本次仅调整时间成长倍率及其数值文档/验证。保留玩家角色、卡牌与出现概率、武器、七种Boss招式、弹幕数量、地图权重、波次预算与70/90秒时长、5秒休整、宝箱怪逃跑、音乐音效和星火复活。

## 公式与计算入口

`t` 为实际模拟时间的分钟数，不是波次数；接口仍接收秒并在集中模块内换算。暂停、抽卡和战败演出不推进模拟时间，继续沿用既有规则。

| 属性         | v1.8.3公式                                   |
| ------------ | -------------------------------------------- |
| 普通生命     | `1 + 0.2t`                                   |
| 普通伤害     | `1 + 0.16t`                                  |
| 普通攻击频率 | `1 + 0.1t`                                   |
| 精英出现概率 | `min(0.03 + 0.006t, 0.48)`，75分钟达到上限   |
| Boss生命     | `3 + 0.6max(0,t−5)`                          |
| Boss伤害     | `2 + 0.32max(0,t−5)`                         |
| Boss攻击频率 | `1 + 0.1max(0,t−5)`                          |
| Boss攻击间隔 | `1.5 / Boss攻击频率` 秒；二阶段再乘一次`0.8` |

普通和Boss生命、伤害、攻击频率不再于60分钟封顶；移除旧Boss 0.16秒攻击间隔下限。二阶段触发仍为生命比例严格小于45%。既有招式预警、延迟发射、初次出生随机等待、每步调度、对象预算及特殊技能节奏均保持，频率倍率不额外乘在已换算的间隔上。

普通技能仍按原基础间隔除以普通攻击频率。召唤师/菌巫原有`7/√A`召唤规则，以及妖精/护卫固定治疗、护盾周期保留，不将所有特殊技能改成同一种间隔。

**移动速度：** 实际v1.8.2为`1+min(0.6,0.012t)`，50分钟后封顶1.6。用户已明确选择移除上限，因此本版统一为`1+0.012t`，60/90分钟为1.72/2.08，之后继续线性增长。敌人存档速度校验同步从固定小于1000改为沿用全局有限数值边界，避免合法长期无尽存档被旧限制拒绝。负数、NaN、Infinity及超过全局边界仍被拒绝。

## 实际属性与关联机制

- 普通怪出生：基础生命×地图难度×普通生命倍率；伤害为基础伤害×普通伤害倍率。精英再叠加原有生命2.4、伤害1.3、移速1.12等修正。
- Boss沿用自身基础生命/伤害，读取独立Boss倍率；不额外套一层普通怪倍率。
- 召唤物出生读取当前时间倍率；分裂子代原生命0.3、伤害0.6、无重复经验等限制保持。
- 流星雨仍为`16×普通伤害倍率`，月蚀弹幕仍为`12×普通伤害倍率`，每次新事件攻击读取当前倍率；没有保留旧的属性分段公式。
- 岩甲0.72承伤系数、水晶巨蟹正面0.35承伤、治疗妖精的治疗比例及防重复周期、护卫的护盾容量和持续时间均不修改。
- 玩家燃烧、暴击及其他伤害乘区不属于敌方时间成长，保持既有计算；敌方技能仍使用各自已经换算的攻击伤害，不重复叠乘时间倍率。

完整十个时间节点（含2.5、7.5、90分钟）的新旧倍率、Boss间隔、精英概率及代表怪物实际属性见 [数值对照](V1.8.3-BALANCE.md)。通过`npm run report:growth`从当前公式与实际spawn生成；旧曲线仅作为明确标注的历史报告夹具保留，不进入游戏包。

代表性的60分钟变化：普通生命1000→13、伤害150→10.6、攻击频率12→7；Boss生命1500→36、伤害250→19.6、攻击频率7.5→6.5。90分钟Boss频率继续升至9.5，一/二阶段间隔约0.157895/0.126316秒。

## 文件与兼容

- `src/data/enemyGrowth.ts`：集中管理每分钟斜率、Boss五分钟平台期、精英概率及攻击间隔。

- `tests/enemy-growth.test.ts`：公式、实际生成、AI计时、召唤/分裂、全部Boss模式、世界事件、特殊防御/治疗及读档验证。

- `tools/enemy-growth-report.ts`、历史夹具和数值对照文档：可重复生成报告；`README.md`及根项目索引同步版本与范围。

Run仍为v5，存档结构和迁移不变。旧档已有敌人继续保留保存的生命、伤害、速度、当前攻击计时与行为状态，避免突然回血/损血或改变Boss阶段；新出生敌人使用新倍率，下一次攻击计时重置时采用新间隔。已经存在的弹幕/伤害区域同样保留快照，后续新世界事件使用新倍率。
