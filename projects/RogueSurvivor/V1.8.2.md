# v1.8.2《糖果魔女的恶作剧》

仅调整糖果魔女庭院宝箱怪行为；其他地图、敌人强度、波次参数、卡牌、武器、经验公式和十二首音乐保持既有规则。

## 行为与波次

- 本波普通敌人预算已处理完毕、无待出场首领资格、场上至少有一只敌人且全部为存活的沉睡宝箱怪时，启动逃跑。
- 每个个体只初始化一次：`0.8 + random(run) × 1.2` 秒，使用原有确定性随机数和小数秒。计时仅随战斗模拟推进。
- 即使之后另一只宝箱怪苏醒或出现其他敌人，已开始的个体计时仍继续；这些情况会阻止尚未开始的个体启动逃跑。
- 原有严格小于190的接近范围、0.7秒突袭预警、正常战斗和死亡奖励保留。庭院中玩家攻击命中（包括由护盾吸收的命中）立即苏醒，并仅取消该个体逃跑。原有受伤苏醒检测作为兼容入口保留。
- 本帧移动接近、玩家攻击与正常死亡结算先处理，再更新逃跑；到期帧内的有效拦截优先。冻结不阻止逃跑计时或近身拦截。
- 沉睡宝箱怪在计时中仍留在敌人列表，最后一只处理完毕后沿用原有5秒休整。逃跑不触发死亡函数、击杀统计、普通经验、抽卡掉落、击杀联动或星火奖励。
- 视觉复用闭合宝箱图片：逃跑前急促摇摆、跳动和金色细环；消失时显示“溜啦！”短提示。碰撞体与位置不受视觉摇摆影响。

## 糖果奖励

每只成功逃跑的宝箱怪在消失前的实际坐标生成一颗糖果，不做普通环境生成的位置偏移。均匀抽取现有正面糖果，每项25%：

| 类型    | 原有拾取效果                               |
| ------- | ------------------------------------------ |
| `heal`  | 治疗25，受最大生命限制                     |
| `xp`    | 获得18经验，沿用数值安全上限               |
| `speed` | 8秒移动速度×1.25，同类刷新时长，不叠乘     |
| `haste` | 8秒自动攻击频率×1.25，同类刷新时长，不叠乘 |

现有环境糖果池没有权重配置，因此正面子集同样均匀抽取。月光是魔法区域提供的增益，不是现有随机糖果类型，本次不扩大糖果效果。绝不抽取减速、虚弱或诅咒效果。

糖果仍由 `tickEnvironment` 统一显示、拾取和计时，原有28秒寿命不变，不在休整或下一波开始时清除。抽卡与暂停冻结模拟时间及糖果寿命。

原有普通环境糖果容量12保持不变。为避免12个普通糖果占满后吞掉逃跑奖励，庭院逃跑糖果带可选来源标记并使用独立的有界容量，最多800颗（与现有敌人安全上限一致）；其他地图不允许此类奖励。总量最多812，存档同样检查来源、正面类型、数量与唯一ID。极端情况下奖励容量已占满，到期宝箱怪保持存活、剩余计时为0，直到拾取或寿命结束腾出容量后再完成一次逃跑；等待时不消耗随机数、不提前移除、不重复奖励。这是明确的容量边界，不改变通常0.8～2秒的独立计时。

## 结构与存档

- `data/mimics.ts`：激活距离、逃跑时间、正面奖励池及容量规则。
- `core/mimics.ts`：共享苏醒入口、启动资格与独立逃跑移除；只在庭院推进逃跑。
- `core/enemyBehavior.ts`：原有行为默认值原样提取，`creatureAI` 保留原导出，避免战斗模块循环依赖。
- `core/combat.ts`：庭院攻击命中苏醒；`core/world.ts`：玩家攻击、死亡结算后执行逃跑。
- `core/environment.ts` / `environmentTypes.ts`：复用现有糖果生成与拾取，增加受限奖励来源。
- `render/scene.ts`：复用素材与有预算的短特效；`data/creatures.ts`：图鉴同步说明。
- `services/storage.ts`：验证可选 `escapeRemaining`（0～2秒）及奖励来源，拒绝已苏醒仍有计时、其他地图逃跑状态、负面奖励、重复糖果ID或非法数值。

保留Run v5、环境schema1、波次schema2及现有旧版本迁移。新字段均可选：旧存档无计时则尚未启动，无来源标记则为原有糖果；加载不补发奖励、不提前抽随机数。新存档按剩余小数秒及原RNG状态恢复，逃跑、糖果生成和敌人移除在同一个同步模拟步骤完成，保存只能获取步骤前或步骤后的完整状态。IndexedDB备份及损坏存档恢复流程保持不变。
