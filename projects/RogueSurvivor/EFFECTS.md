# 正式特效资源与替换接口 · v1.9.0

本版使用 OpenAI 内置 `image_gen` 生成原创二次元幻想特效，不使用第三方素材包。美术与逻辑判定分离；文件不包含脚本，也不改变伤害、轨迹、范围或冷却。

## 美术规范

- 我方：青白核心、深青轮廓、少量星光金与淡紫；烬火保留金橙火焰，范围轮廓仍为青蓝。
- 敌方：危险橙红核心、深紫边缘；自然、水晶、糖果、月蚀和镜界主题仅在轮廓内部增加材质。危险轮廓不受贴图替换影响。
- 治疗/增益为薄荷绿和金色，护盾为青白薄膜，复活为紫金星旋。中心留空，避免遮住角色。
- 静态图统一192×192，透明边缘留白；贴图只使用普通透明混合，不叠加全屏泛光。特效中心与世界坐标一致。扇形材质缩放并内接在真实扇形内，条形材质按真实长度、宽度和角度显示。

## 来源与处理

`art-source/v1.9.0/` 保存生成结果的无损WebP副本（去除非必要元数据），以及切片预览。`player-status.webp`含16项，`boss-world.webp`含8项，`impact-sequence.webp`是四个原始连续动作帧。部分初稿存在浅色底，Boss图已通过生图编辑重新去底；命中序列采用边界连通的中性背景清除，保留封闭的白色能量核心。

运行 `python tools/prepare-v190-effects.py`（需要Pillow）重新裁切、居中、清理透明边缘并压缩。四帧命中序列使用相同缩放与中心，避免逐帧自动裁切导致大小跳动。不是GIF，也不把缩放静态图冒充生成动画。

运行资源位于 `public/assets/v1.9.0/effects/`，共24张静态WebP、一张768×192四帧WebP，以及清单`manifest.json`。总像素约103万，文件约410KB；全局资源清单与`src/data/effects.ts`统一注册。运行时不请求生成服务。

## 工坊替换与回退

25个`vfx.*`ID均在资源工坊的「正式特效」分组中，可替换静态PNG/WebP、调整缩放偏移、恢复默认、导入导出；既有文件类型/尺寸/体积校验不变。`vfx.impact`默认4帧192×192；自定义精灵图可使用原有帧宽/帧高/帧数/帧率参数，也可改为静态图。

原`projectile.*`自定义图片仍优先于新版弹道素材；原`skill.*`图标与自定义领域图片仍保留。新ID提供更细的特效替换入口。缺图或超时会使用原投射物/程序化反馈；判定轮廓始终保留。角色动作资源优先加载，普通默认美术和新增可选特效在其后启动；新增特效有独立的只执行一次的加载缓存，不阻塞战斗。透明素材只加载解码一次，Phaser纹理和精灵池复用；切换波次/读档不会再次下载同一默认资源。

## 层级和质量预算

地面材质1、怪物状态3、我方弹道5、命中7、玩家状态9、玩家主体10、敌方技能材质11/弹道11.5、危险轮廓12。伤害数字沿用8，危险层在其上方。背景和地形规则不变。

复用设置中的完整/简约选项，不新增存档字段。完整画面最多96个可选材质精灵，已有高密度条件下上限64；简约画面24。优先保留玩家关键状态与区域材质。达到预算只省略额外光环/爆发等装饰，**不省略真实弹道、敌人、危险轮廓、我方范围线或经验**。玩家主动选择低画质时才简化地图装饰，保持原规则。瞬时反馈队列最多96项，观察记录随敌人离场删除；精灵复用且数量受现有对象上限及装饰预算约束。

出生、命中、升级等短暂反馈不写入存档；读档重建观察基线，避免恢复瞬间给所有敌人补播出生/死亡。暂停和抽卡不推进其模拟时间；战败和复活素材使用原有独立演出计时。

## 开发验证

`tools/effects-harness.html`是仅通过Vite开发服务器访问的固定场景入口，不包含在生产入口中。它停止战斗模拟、只驱动实际GameScene渲染，便于相同敌人/弹幕快照的前后对比；不是玩家通关模拟。

```bash
npm run dev -- --port 4176
# 在另一个终端
npx tsx tools/effects-benchmark.ts
```

可用`VFX_BASE_URL`、`VFX_OUT`、`VFX_LABEL`选择旧版/新版服务和结果目录；Windows可使用PowerShell环境变量语法。默认每场景3次×4秒采样，记录FPS、JS绘制时间、敌人/弹幕/领域、精灵数量及可用的JS堆值。原版对照基准为4c06195，使用其源代码配合同一harness；不以云端低FPS调整游戏规模。结果与局限见[V1.9.0.md](V1.9.0.md)。
