# v1.7《指尖远征》

本次仅扩展输入与界面。角色、武器、技能、怪物、Boss、波次、掉落、经验、卡牌与复活数值均沿用v1.6，Run仍为4、IndexedDB仍为1，不清除历史与存档。

## 操作与布局

- 默认通过`any-pointer: coarse`及`maxTouchPoints`识别输入能力，无UA判断；“显示触屏控制”设置支持自动、始终显示、关闭摇杆。旧设置缺字段时为自动，非法值也回退自动。
- 左下固定半透明摇杆，16%半径死区，超出半径夹紧。有效方向归一化，与WASD相同移动速度，斜向不加速。键盘有移动输入时优先键盘，避免混合设备的向量叠加。
- 复用Q／E／R／闪避栏，改成真实按钮。技能沿用实际冷却，显示不可用状态和按压反馈。Pointer Events逐指针持有；捕获不可用时由文档事件维持拖动。指针松开、取消或丢失捕获仅释放自己的控制权。兼容鼠标点击不会重复触发；键盘与辅助技术的按钮激活仍可用。
- 战场画布轻触指定落点，再按技能。瞄准提示可恢复自动。触屏方向／区域技能优先选择原射程和视线检查内的有效敌人；无敌人时方向技能沿移动或上次朝向，区域技能以脚下为落点。霜环、星幕、复苏始终自身释放；定点仍遵守450施法射程。电脑鼠标与快捷键不使用触屏自动瞄准。
- 暂停、抽卡、查看卡册／图鉴、死亡演出、结算、失焦、隐藏页面及视口变化时清除摇杆与待发命令，恢复后须重新触摸，不残留移动。
- 横屏推荐但不强制。手机右下技能2×2，左下摇杆，顶部核心状态；竖屏卡牌单列、横屏紧凑三列，弹窗独立滚动。安全区域处理覆盖四边；通过VisualViewport与CSS尺寸同步画布逻辑尺寸，旋转与地址栏变化后重算。短横屏缩小小地图，避免与瞄准按钮重叠。
- 只在战斗画布、摇杆和技能区域限制浏览器手势；菜单仍可滚动与缩放。装备按钮仅在装备／等级或资源变化时更新，保留跨HUD刷新的触摸与键盘焦点；装备图标可点击进入暂停说明，完整技能／装备说明无需悬停。
- 首次开始、触摸摇杆或技能可解锁音频；复用原音频实例与地图歌单，不因技能点击重建或重启歌曲。抽卡连续播放、手动暂停／失焦暂停等策略保持。

## 验证记录

验证命令：`npm test`、`npm run build`、`npm run test:e2e`、`npm run test:mobile:webkit`。完整跨平台回归以对应PR的必需CI检查记录为准，全部通过后才合并。

本地WebKit完整移动套件结果：10项通过，1项CDP专用用例跳过；独立指针、多点持有、菜单、复活与音乐检查均运行通过。

本地初验：283项单元测试通过（保留原276项，新增7项输入／瞄准规则测试）；TypeScript与生产构建通过；`npm audit --audit-level=moderate`报告0项漏洞。Chromium与WebKit均实际运行六种视口；Chromium另使用CDP双触点，WebKit使用逐指针事件。完整86项Chromium回归和11项适用WebKit用例纳入CI；WebKit仅跳过不支持的CDP用例，仍运行独立指针验证。CI在Linux／Windows执行既有全套Chromium回归，新增Linux WebKit任务，未删除旧用例或降低原断言。

本地环境为Linux、Node 24.19.0、无真实手机。WebKit系统依赖初次安装权限不足，后从系统软件源解包至临时目录供浏览器使用；没有修改项目依赖或降低游戏规模。Vite保留既有Phaser大包提示，不影响构建。

指定截图位于`validation/v1.7/`：390×844、844×390、393×873、873×393、768×1024、1280×720。测试检查技能、闪避、暂停、摇杆在屏幕内、无横向溢出、旋转后恢复布局，以及设置／菜单返回。

多点验证分两类：Chromium CDP `Input.dispatchTouchEvent`发送独立ID的同时触点，并验证右手释放后左手移动继续；Chromium／WebKit另通过独立Pointer Events验证斜向移动、技能、取消、暂停及恢复。普通单击不作为多点触控验收证据。

自动化覆盖正负抽卡、刷新、卡册、四类图鉴、六种主动技能、闪避、存档恢复、复活和通关后继续无尽，以及音乐不重复创建。既有单元与E2E测试保留，包括键盘／鼠标、Boss、标准／无尽、卡牌与资源工坊回归。

### 限制与真机待验证

- 桌面Chromium移动视口／触摸模拟、Linux WebKit测试均不等同真实Android Chrome或iPhone Safari。未进行真实手机、iPad或桌面Edge人工测试。
- 刘海与底部手势区域采用CSS安全区域；真实浏览器地址栏伸缩、系统边缘返回手势、中断电话、切换应用及蓝牙外设仍需真机确认。
- 不锁屏幕方向。浏览器缩放后的VisualViewport使用原有窗口坐标兜底；实际不同系统缩放和辅助功能需要真机检查。
- 云端软件渲染不代表手机GPU性能；本次不执行长时间压力测试，不据云端帧率降低任何战斗数值。
- 固定摇杆第一版无自定义位置／大小编辑，技能使用自动或战场定点瞄准，没有新增第二摇杆。
