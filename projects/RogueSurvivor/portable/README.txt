RogueSurvivor - Windows portable edition
========================================

1. Extract the entire ZIP file to a normal folder (do not run inside ZIP).
2. Double-click Start-Game.bat.
3. Your default browser will open http://127.0.0.1:18765/ automatically.
4. Keep the command window open while playing. Ctrl+C stops the server.

Requirements: Windows with Python 3 installed and a modern browser.
Node.js and internet access are NOT required to play the packaged game.

If a browser does not open, manually visit http://127.0.0.1:18765/.
If port 18765 is busy, close the previous launcher or conflicting program.
Do not change the port: browser save data is tied to the address and port.

Saves are stored by the browser for this local address, not in the game folder.
Use the same browser/profile for saved progress. Browser private mode or
clearing site data may remove saved games. Existing GitHub Pages saves
will NOT automatically appear in the portable version.

The server only listens on 127.0.0.1 (this computer). No accounts or
remote game server are required; all packaged assets are served locally.
