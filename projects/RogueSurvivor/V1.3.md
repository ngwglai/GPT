# v1.3「星光少女与魔法世界」

## 交付范围

原三角色的稳定ID、初始武器、技能、生命、速度保持不变：森林精灵莉芙（逐星游侠）、珊瑚星剑士莓露（余烬守卫）、星月魔法师露娜（月棘术士）。每人提供完整立绘、选择界面用立绘与独立头像、对应Q版战斗图。选择版本复用完整立绘，不谎称为另一张独立生成。战斗单图采用呼吸、移动翻转、受击闪烁和原有动作特效，不提供虚构的多方向逐帧动画。

十种敌人（七普通、三Boss）、五武器、六技能、五类自动弹道及敌方弹道、地表、花蘑菇、树、石碑、水晶岩、经验星晶与命运/恶作剧/礼盒/普通/稀有/史诗/机制图标均实际使用原创图片。菜单为魔法森林原画和少女立绘，选择/HUD/升级/卡册/图鉴/暂停/结算共享奶油纸张、粉紫边框与暗紫文字。原名称保留用于准确描述规则，角色介绍与提示改为轻快幻想风格。

本次不修改核心规则、卡牌参数、敌人属性、碰撞、随机数、存档版本及迁移。立绘与战斗资源的视觉尺寸互不影响碰撞；玩家视觉由66调整至80像素。六首用户音乐保留。

## 美术规范

- 立绘约6头身，战斗约2.7头身；三人通过发型、衣装、武器、帽子区分。
- 细紫灰轮廓、赛璐璐阴影与轻柔渐变；奶油白/珊瑚粉/薄荷绿/星月紫/少量星光金。
- 小尺寸战斗图保留大轮廓；怪物通过尖耳、孢子炮、法杖、岩甲及Boss复杂轮廓区分职责。
- 地表低对比、减少细节干扰；地图装饰位于预警和角色下层。
- 危险预警、精英光环、受击、数值和敌方弹道保留清晰对比，不用可爱外观隐藏危险。
- UI图标与卡面共享魔法星、花瓣、水晶、丝带；纯负面用深紫/恶作剧星，混合契约保留暖色边框。

## 生成与处理

全部新增图片来自本次 OpenAI 内置 `image_gen`，无第三方生成API、付费调用配置或商业素材。先生成精灵立绘/Q版、史莱姆和草地样板，接入截图检查，再生成剑士、魔法师、怪物表、图标表、透明环境/弹道表、透明环绕物/领域表及森林背景。

`art-source/` 保留八张使用中的生成母图（无损WebP）。图标背景移除尝试效果不佳，未把它宣称透明成功：图标表用于有底卡牌/技能图标；实际战斗弹道与环绕物使用另行生成的透明素材。未采用的编辑尝试不混入交付资源。

`tools/prepare-art.py` 只负责机械裁切、透明边界整理、尺寸归一、WebP编码及地表处理。地表以低对比原画为基础，将256像素纹理镜像组成512像素瓦片，边界连续，不宣称生成原图本身完美无缝。执行 `python -m pip install Pillow` 后运行 `python tools/prepare-art.py` 可从母图复现成品和清单；图像生成本身不具备可承诺的逐像素可复现种子。

## 资源接口与体积

- `public/assets/manifest.json`：版本、来源与稳定ID映射；当前54个图片ID、45张独立映射图片，另有原有矢量回退ID。
- `src/data/visuals.ts`：运行时统一映射与卡牌图标分类，不在战斗规则中散布图片路径。
- `characters/`、`enemies/`、`maps/`、`weapons/`、`effects/`、`cards/`、`ui/`：浏览器资源，以清单统计为准；母图约13MiB不进入网站构建。
- 优先级：资源工坊的自定义图 > v1.3生成图片 > 原矢量美术。头像、立绘、卡面、背景、场景装饰也纳入资源工坊。
- Phaser按唯一URL缓存解码Promise，启动时一次加载战斗图，不在每帧重新解码；HTML菜单图不载入Phaser战斗纹理。原对象池、屏外剔除、数量与粒子预算保留。
- 地表使用单个TileSprite，按世界坐标滚动。只在尺寸/纹理改变时重设，适配窗口缩放；自定义地表保留缩放与偏移。
- 删除/损坏某张生成图只回退相应资源，恢复默认会恢复生成美术。自定义图校验与24MB资源包边界保留。

## 验证记录

138项单元测试通过，生产构建通过。最终独立完整27项生产Chromium E2E通过（5.4分钟），包含原有24项与新增3项美术/回退/地表缓存回归；没有降低旧断言标准，文案断言按新界面名称更新。原密集战斗用例146敌人/五满级武器观测18FPS，与高生命持续夹具不是同一种负载。最终截图颜色修正后补充复验新增美术用例。首轮24项回归21通过：两项旧界面文案断言已按新名称更新，另一项在并行渲染压力时导航白页超时；未删除原测试或放宽45秒超时。

实际检查的截图在 `validation/v1.3/`：主页、三角色选择、战斗、暂停、当前构筑、卡牌手册、密集场景、胜利结算。菜单背景的相对URL误解析在截图检查中发现并修正为基于页面的绝对URL，适配Pages子路径。

独占浏览器对照（Linux系统Chromium/SwiftShader软件渲染，1440×900）：同一7201秒无尽快照、五种满级武器、请求160敌人/受上限与碰撞约束实际147敌人，敌人夹具生命1e7、玩家无敌，仅用于持续渲染压力。各实测约61秒、每10秒采样一次；基线为更新前main提交02fe211（完整SHA见baseline报告对应源版本），美术版普通战斗图128像素。原版采样FPS为11/7/7/7/7/7，新版10/6/5/6/6/5，低中位数约从7降至6。两者都在此极端软件渲染夹具中较慢，不能据此承诺低端机器60FPS；壁钟推进与游戏逻辑时间因限步不相同。两组浏览器均无脚本错误。

新版堆采样约19–44MB、有GC回落；不代表GPU/原生图片内存，不宣称已经证明真实浏览器两小时无泄漏。每个生成URL在整个截图/重载流程最多请求2次（含整页重载），未出现逐帧图片请求；按URL缓存的解码与地表重复替换另有E2E覆盖。清晰度与透明边缘已实际查看。原始指标在browser.json/baseline.json。

逻辑压力使用既有simulate：ranger/77与mage/88分别推进7201秒，保留Boss、掉落、五武器、60分钟洗牌及存档校验；无敌仅用于压力时长，不是自然通关率。原始结果见stress.json和stress-mage.json。

## 已知限制

没有四/八方向完整手绘逐帧动作；人物左右移动采用水平翻转，待机和移动采用程序变换。图标不是每张卡独立大插画，而是按机制/稀有度/正负分类复用，命运洗牌有专属魔法卡册图。无新增关卡与战斗机制。镜像草地会有重复图案，但边缘连续。真实低端硬件与Firefox/Safari、浏览器真实连续两小时尚未验证；不承诺软件渲染高密度战斗60FPS。

战斗优化：普通怪物、Q版角色、环境小物、环绕物输出128像素；Boss保留256像素，头像256、立绘至768，菜单背景1672。场景地表重载前先将TileSprite脱离旧自定义纹理，避免删除后仍被绘制。

截图工具：先启动预览服务器（默认4176），运行 `npx tsx tools/visual-check.ts`；`VISUAL_BASE_URL`可覆盖地址，`VISUAL_QUICK=1`只更新界面截图、不执行压力场景，`VISUAL_OUT`可覆盖输出目录。浏览器使用Playwright默认安装版本，Linux环境可通过PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH指定系统Chromium。

### 启动纹理与验收隔离补充

合并后Windows复验出现多处页面/worker关闭超时，保留失败日志。为减少启动与多局重复测试的资源占用，Phaser不再预建55张矢量回退纹理：只预建ui.gem和map.ground，其余缺图时按需创建。原矢量回退仍完整保留。新增浏览器断言限制菜单启动时128像素回退Canvas数量；美术用例使用独立worker浏览器，结束后释放，再执行原战斗/卡牌组。全部27项断言与45秒超时保持，未增加自动重试。

Windows验收补充：旧Headless Shell 156.0.8078.4在页面创建前出现browser.newContext失败、Skia mailbox错误及关闭超时。Windows测试改用同次Playwright安装的完整Chromium新无头模式（launchOptions.channel=chromium）；仍为WebGL真实生产构建与媒体测试，不mock渲染/音频，不更换引擎版本，不延长45秒、不删除断言。Linux已验证的配置保持。显式提供系统浏览器路径时保持调用者选择。
