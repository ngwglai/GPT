# v0.4.0 变更

- 新增 `lan_server.py`：aiohttp HTTP/WebSocket、临时房间、随机身份、座位锁定、房主开始/续局、重连、连接状态。
- 原 `web_server.LocalTable` 和 GameEngine/TableService 继续承担连续牌局和规则权威；单机与房间完全独立。
- 唯一麻将核心改动：`GameEngine._presentation_events(viewer)` 按观看者过滤暗杠牌型，修复表现层旁路泄露；规则算法、规则配置和旧测试不变。
- 新增 `web/lan.html`、`web/lan.js`、`web/lan.css`；共享原 `app.js` 渲染函数，保留 `presentation.js`。
- 原首页移至 `web/local.html`，新首页提供模式选择。
- Windows 启动脚本自动准备虚拟环境和依赖。
- 新增网络测试，具体结果见测试报告。
