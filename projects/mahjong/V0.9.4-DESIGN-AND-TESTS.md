# 青雀麻将 v0.9.4 — 固定摄影机长方体透视试用版

基于资料库 v0.9.3 完整包。游戏规则与网络协议不改；版本号更新为 0.9.4。保留原始素材、Windows 启动脚本和历史原型。

## 本版设计

- 实际单机、联机页面加载 `web/cuboid-scene.js` 和 `web/v094.css`，原 `perspective.js` 与 `table-scene.js` 保留为历史原型及事件辅助。新渲染入口替换旧平面映射。
- 固定几何参数：俯角30°、距离100、焦距25，牌宽1、长1.36、厚0.45；桌面半边12.5；中央框半边3；牌河起始3.7、横偏-2.5、横间距1.02、纵间距1.38；牌墙距离9.2、偏移0.70、间距1.02；手牌距离11.7、间距1.02。配置集中于 `cuboid-scene.js` 顶部 `config`。
- 四方向、躺牌与立牌均使用八顶点投影和可见面判断。面纹理以单应矩阵精确映射到投影四边形。深度使用面中心的摄影机纵深排序（非深度缓冲）。整个场景根据窗口统一等比缩放，不改变摄影机参数。
- 牌河默认三行七列，超过21张时扩列至11列、最多四行；单家44张以上的部分用牌河详情查看。上金和报听按公开事件顺序与普通弃牌共同呈现，报听牌一律背面朝上。未公开牌型不从前端推导。副露与十三幺公开拾牌共享手牌右端；全部同向平放，来源用小标记表达。
- 中央框显示局数、余牌、骰子、四家风位和分数；庄家仅风位金色、行动席用方向框高亮。左上角金牌，右上角控制与设置，顶部取消不透明横栏及重复对局HUD。玩家身份在南北自家左侧、东西手牌外侧。操作和常用托管/拾牌切换覆盖己方牌墙。原手牌按钮仍使用服务器合法操作，点击区域匹配投影轮廓。
- 「完整桌面」为俯视检查模式，已公开/本地允许查看的手牌平放，联机对手暗牌仍保持隐藏。

## 验证记录

1. `python -m unittest discover -s tests -t . -q`：192项通过，含服务端完整联机牌局（89次授权操作、流局、下一局发牌）。旧历史UI源码检查亦通过，但并不代表新版浏览器视觉验证。
2. `node tests/v094_cuboid.cjs`：通过。覆盖参数、近远比例、四点单应映射、8种视图、暗牌隐藏、同高度物理碰撞、每家44张牌河压力、上金/报听时间顺序、四杠及取消横置。
3. `CHROMIUM_PATH=/usr/bin/chromium python tests/v094_offline_browser.py`：通过。真实规则引擎快照驱动的离线 Chromium 测试，验证掷骰、选牌、出牌请求参数、俯视切换、手机横屏布局、联机净化视图己方居中和他家手牌无ID、合成拥挤场景。无 JS pageerror。该测试的 API 由快照代替，非真实浏览器 WebSocket 端到端；当前测试环境拦截浏览器访问本地服务地址。完整联机端到端及 Windows 实机需用户本地复验。
4. `validation/v0.9.4/` 中截图为离线 Chromium 实际渲染结果；`mj94_stress.png` 为合成布局压力测试（非真实合法牌局）。

旧版单独的浏览器验收脚本依赖历史 DOM 选择器，不能作为新版验收结果；新的几何与离线浏览器脚本见上。`tests/ui_smoke.cjs` 主要牌墙/牌河选择器已适配新版，但未运行完整 jsdom 联机脚本。

## 启动与调参

完整解压，双击 `启动网页版.bat` 或 `启动局域网联机.bat`。先使用新目录，不覆盖旧版。如需微调摄像机或布局，修改 `web/cuboid-scene.js` 的 `config` 并刷新页面。建议首先用单机固定种子42检查出牌与特殊操作，再使用横屏手机或局域网联机验证。
