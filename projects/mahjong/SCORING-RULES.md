# 青雀麻将计分规则

- 基础分 B = 1 或 5，开局前选择（单机重置整场，联机创建房间），整场固定。起始累计分为0。
- 单人支付基础分为 B×M×D：自摸时 M=2，否则1；付款者与胡牌者中存在庄家时 D=2，否则1。
- 最终胡牌者每个已上金由应付胡牌分的对手各付5；其他玩家的上金没有收益。
- 每个完成的明杠或补杠由另外三人各付1；暗杠各付2。与胡牌与否无关，流局也照付。补杠被抢未完成不计杠分。
- 点炮者在正常胡牌分之外加付5。抢补杠（可选规则）按有责任来源的非自摸胡牌处理，来源者加付5。
- 多人实际选择胡牌时，依东南西北出牌顺序取离来源最近者为唯一赢家；其余选择胡牌者免付赢家基础分和上金分。所有人的杠分照常计算。选择过牌不免付。
- 特殊牌型、报听、杠上开花等不改变分值，不再使用旧版报听点炮最低分规则。
- 本局结束时统一计算每个有向支付，行付款、列收款，主对角线为0。净分=收入−支出，四人净分之和为0；下一局只累计一次，重置整场清空累计分。

`result.settlement.items` 包含 `base_score`、`other_hu`（其他提交胡牌的席位）、`matrix`（东南西北顺序）和 `payments`（基础、上金、明/补杠、暗杠、点炮及合计）。该明细仅在本局结束后公开。前端的「详情」显示逐笔支付，结算框显示各家本局净分。

本文件优先于早期历史文档的临时计分配置。旧的任意倍率/加算 hook 已由正式规则替代。
