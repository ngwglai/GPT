# v0.9.8 30°手牌与圆润立体麻将

基于 v0.9.7 完整包，仅改变共享渲染层和版本信息，不改变麻将规则、AI、网络协议、启动脚本及原有素材。

- 保持桌面俯视角45°、近远端宽度比1.4、其余牌区和完整桌面90°视角。视觉南家暗手牌使用独立30°正交投影，保留 v0.9.7 的参考对家2倍宽度、底部锚点与副露空间避让。统一水平面为角度基准，投影为 x'=x、y'=-(y sin30°+z cos30°)，再经等比缩放和平移；不借助画面整体压缩。
- 所有麻将使用同一圆角长方体几何：牌宽1、牌高1.36、厚0.45，圆角半径0.085（牌宽8.5%）。6个平面中心、12个四分之一圆柱棱、8个球面八分体角；每90°圆弧5个细分，圆角网格缓存于局部坐标。每个可见面/曲面片由相应相机投影，曲面按法线光照与牌背/牌面颜色着色；牌面纹理仍使用原有单应矩阵。实体外轮廓的凸包用于实际按钮点击与选中高亮；排列避让仍使用保守的原始外接长方体边界。桌面圆角不变。
- Node 五组测试通过：投影、碰撞、区域布局、30°手牌可见面、12棱8角及圆角网格半径、点击轮廓与副露避让。
- Chromium 真实引擎快照驱动测试通过：掷骰、点击选牌、出牌请求ID、切换90°视角、五种屏幕尺寸、LAN脱敏视角、满牌河与副露压力场景。截图见 validation/v0.9.8/。未在 Windows 或手机实机测试；离线浏览器快照测试不等于真实 WebSocket 浏览器端到端测试。
- Python unittest：192项全部通过，含真实LAN服务端89次鉴权操作完整一局及下一局发牌。
