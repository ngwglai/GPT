# v0.10.0 渲染重构与六筒调整

## 实现
- 统一电脑、平板、手机渲染路径；45°桌面、30°独立手牌、1.4近远宽比、8.5%圆角不变。
- `web/assets/sprites-v100.json` 含170个离线预烘焙精灵（136个固定牌墙位置和34种标准尺寸手牌）；可用 `tools/bake_tile_sprites.py` 重新生成。其他位置保持原三维几何，首次遇到时在一个共享临时 Canvas 中光栅化为 PNG，缓存复用。牌面纹理通过局部三角形近似单应变换；不用实时 SVG 曲面节点。缓存估算解码像素上限24 MiB、384项，并非浏览器总内存上限。
- 按麻将逻辑键复用单个 img 节点；局部修改图片、位置或顺序，删除消失的牌。中心信息单独更新，手牌碰撞轮廓与原投影一致。选牌不重复生成整桌精灵；查看牌河和结算不销毁桌面节点。
- 后台接收状态但不绘制或播放积压事件，前台恢复渲染并重新请求本地最新状态。服务端原有 AutoRunner 已独立于浏览器，本次不修改 AI 和规则。浏览器仍可能节流后台网络和计时器。
- 六筒三排圆心纵坐标从 15/33/51 变为 10/34/52（50×66矢量坐标），上排到中排间距从18到24，下面两排保持18。图案源程序同步更新。
- 开发者控制台 `MahjongCuboid.diagnostics()` 可查看缓存命中/未命中、节点复用、最近一次场景渲染耗时和估算缓存占用。

## 验证
- Python unittest 192项通过；5组 Node 几何及布局测试通过。
- Chromium 离线浏览器真实引擎快照测试：掷骰、选牌、出牌、俯视切换、五种窗口大小、联机脱敏视角、满牌河副露、DPR3触屏模拟、反复更新缓存上限及模拟后台恢复通过。
- 136张初始牌墙全部命中预烘焙精灵，零实时曲面生成；掷骰后136个麻将图像节点；合成压力场景220个图像节点；无旧式圆角SVG节点。
- 一轮环境测量初始场景约89ms，掷骰约163ms，出牌约93ms；不含全部页面加载、解码与合成耗时，不是手机实测。未在真实 iOS Safari / iPadOS Safari 验证，不保证网页进程异常已彻底解决。
