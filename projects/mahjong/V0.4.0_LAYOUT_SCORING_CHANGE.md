# v0.4.0 前端布局与默认计分补丁

## 默认计分

Web / LAN 的 `LocalTable` 现在会为 `GameEngine` 注入 README 示例中的默认 `ScoreEngine`：

- 平胡基础：1
- 每张已上金的金牌加成：1
- 庄家倍率：2
- 点炮倍率：1
- 自摸倍率：1
- 庄家作用范围：`EITHER_PARTY`
- 自摸付款：`EACH_OPPONENT`

流局时的上金/杠等附加结算仍未定义，因此流局后如涉及未配置策略，计分状态仍可能显示待配置；没有擅自补地方规则。

## 联机视角

局域网模式按当前登录玩家旋转桌面，只改变显示位置，不改变真实东南西北座位和任何规则状态：

- 自己：下方
- 下一家：右侧
- 对家：上方
- 上一家：左侧

单机四家明牌测试模式继续使用原有固定方位。

## 牌河

四家牌河已移入四面牌墙围成的区域，并随玩家视角一起旋转。每条牌河与同一视觉方向上的玩家和牌墙保持对应。
