# CausalLab v0.1 · 因果推断实验室

面向学生、自学者与算法实验者的本地交互式教学工具：编辑因果 DAG 和结构方程，固定随机种子生成合成样本，比较观察性关联、调整估计与 `do` 干预效应。它不处理现实数据，也不提供未经验证的现实因果结论。

与仓库的其他实验室不同，本项目研究因果识别、混杂与选择偏差；不修改其他项目业务代码。无后端、数据库、API、遥测、外部字体或分析服务。安装依赖需要联网，运行与计算完全在本机浏览器中完成。

## 安装、启动与验证

需要 Git、Node.js **22.12+**（建议 Node 22 LTS）及随附 npm。所有命令从仓库根目录开始，在 Windows PowerShell / CMD 与 Linux shell 中均可逐行执行：

```sh
cd projects/causallab
npm ci
npm run dev
```

打开终端显示的 `http://127.0.0.1:5173`。如果端口占用，以 Vite 输出为准。按 Ctrl+C 停止。生产构建与本地预览：

```sh
npm run build
npm run preview -- --port 4178 --strictPort
```

打开 `http://127.0.0.1:4178`。预览只绑定本机；没有部署外部服务。不要直接双击 `dist/index.html`，应通过预览服务器加载模块。

检查与测试（E2E 前必须重新 build，使用真实生产产物）：

```sh
npm run lint
npm run typecheck
npm test
npm run build
npx playwright install chromium
npm run test:e2e
npm audit --audit-level=moderate
```

Linux 若缺少浏览器系统库，使用 `npx playwright install --with-deps chromium`（系统包安装可能需要管理员权限）。Windows 使用 `npx playwright install chromium` 即可。可用 `CHROMIUM_PATH` 指定实际浏览器可执行文件；通常无需设置。E2E 自动启停本机 4178 端口，运行前请停止手动预览。CI 在 Linux / Windows 独立运行以上检查，汇总进入根 `CI required`，没有发布步骤。

## 操作与复现

1. 加载 A/B/C 案例，检查因果图、方程和参数。绿色节点是二元变量，蓝色是连续变量。
2. 创建、改名或删除变量；选择父/子节点和系数建立有向边。自环、有向环会被拒绝。每个变量显示父节点与全部后代。
3. 选择处理、结果和可选二元分组变量，设置样本量与种子，点击生成。默认 `n=10000, seed=42`，上限 `n=20000`。
4. 查看描述统计、直方图、观察性均值差、OLS、处理父变量调整及分组统计。均值差方向统一为处理 1 减处理 0。
5. 设置干预 a/b（默认 0/1），重新生成实验，再执行 `do`。查看两个结果分布、均值、真实 ATE、配对样本 ATE、标准误、95% 区间与误差。
6. 导出实验参数 JSON。再次导入相同文件，点击生成与干预，即可重现相同数值；不依赖系统时钟。修改模型、样本参数、分析变量或干预值会清空旧结果，防止混用。
7. “恢复加载时模型与参数”回到最近加载/导入快照；“清空实验结果”保留模型和设置；“重置为默认模型”回到案例 A。

变量 ID 是不可编辑的稳定引用，变量名称可自由修改。新建节点使用 V1、V2 等 ID；要自定义 ID，可导入通过校验的模型 JSON。编辑中的非法参数作为草稿保留并显示错误，生成和导出相应暂停；导入失败不会替换已有模型。

## 模块与数学定义

- `src/core/model.ts`：序列化领域模型、严格校验、DAG 排序、后代遍历、边操作；不依赖 React 或界面坐标。编译缓存以验证后的模型值为键，最多 16 项，缓存内容冻结。
- `random.ts`：固定 Mulberry32 无符号 32 位 PRNG，种子为 `[0, 2^32−1]` 整数；不使用 `Math.random` 或系统时间。
- `simulation.ts`：采样、条件筛选、结构干预、解析期望；三者分开实现。
- `statistics.ts`：统计汇总、估计器、标准误、区间与直方图。
- `analysis.ts`：组合观察分析和配对干预实验。
- `serialization.ts`：有界 JSON 校验、实验导出及结果 JSON/CSV。
- `App.tsx` / `Charts.tsx`：中文交互界面及轻量 SVG 图表；没有大型图形库。

### 结构方程与外生噪声

连续变量：

`V_i = intercept_i + Σ_j weight_ij · V_j + noiseStd_i · ε_i`，其中 `ε_i ~ N(0,1)`。

二元变量：

`p_i = intercept_i + Σ_j weight_ij · V_j`，`V_i = 1{U_i < p_i}`，其中 `U_i ~ Uniform[0,1)`。

二元节点只允许二元父节点，校验所有父变量组合下概率范围 `[0,1]`（允许 1e−12 浮点舍入容差；采样时仅裁掉该舍入越界）。二元节点的 `noiseStd` 必须为 0；其随机性来自均匀外生噪声。所有节点的外生噪声相互独立，行与行独立。正态噪声由 Box–Muller 转换生成。

每行按模型原始变量数组顺序，为每个节点消耗两个均匀数，再按拓扑顺序计算方程。因此干预替换方程不会改变随机数消耗。相同模型（含变量数组顺序）、参数和种子可复现；重新排列变量定义可能改变具体随机实现，但不改变总体机制。

### 描述性统计与观察性估计

- 样本均值 `ȳ = Σy/n`；样本方差 `s² = Σ(y−ȳ)²/(n−1)`，使用 Welford 更新。空样本均值未定义，单样本方差未定义，界面显示“—”。
- Pearson 相关 `r = Σ((x−x̄)/s_x)((y−ȳ)/s_y)/(n−1)`；常量或不足 3 个样本时不适用。
- 二元朴素处理效应：`Δ_obs = mean(Y|X=1) − mean(Y|X=0)`。每组至少 2 个样本。标准误为 `sqrt(s1²/n1+s0²/n0)`；使用 Welch 自由度的 95% t 区间，小自由度向下取整。
- 基本 OLS：`Y = α + βX + γᵀZ + residual`，使用中心化/缩放、两遍修正 Gram–Schmidt QR 求解，不直接求正规方程逆。报告 β 及同方差假设下的 `SE(β)` 和 t 区间。共线、常量解释变量或残差自由度不足时报告原因。
- 对二元处理的二元父节点集合进行分层标准化：`Σ_z P̂(z)[mean(Y|X=1,z)−mean(Y|X=0,z)]`。标准误为 `sqrt(Σ_z P̂(z)² SE_z²)`，区间是固定经验分层权重的渐近正态区间，不计分层构成估计误差。某个观测分层缺乏组内重叠或每组不足 2 个样本，则拒绝报告调整差。
- 连续处理或含连续父节点时，以处理全部父节点作为 OLS 控制项。当前仿射、独立噪声、完全观测的 DAG 中，该调整集满足后门准则；连续处理的调整 OLS 报告单位系数。它不自动验证现实中的可交换性、隐藏混杂或模型设定。
- 条件分组只筛选原始观察数据，并展示各组两处理组的样本量、均值、差与相关。分组变量是后代时，明确提示不能把该条件关联当作混杂调整。连续处理不适用按 0/1 计算的分组均值差。

均值/回归区间使用 95% t 临界值表（df≤30），其后使用三阶大自由度展开；大样本趋于 1.959964。有限样本、非正态及异方差下不保证名义覆盖率。OLS 未实现稳健/聚类标准误。

### do 干预、真实效应与样本误差

`do(X=x)` 将 X 方程临时替换为常量，切断其父节点作用。其他方程与外生噪声保留，仅对后代按拓扑顺序重算，非后代保留原行的值。

`ATE(a,b) = E[Y | do(X=b)] − E[Y | do(X=a)]`。二元处理通常取 a=0、b=1。连续处理的区间总效应与单位回归系数的统计口径不同。

本项目的所有条件期望都是仿射函数，因此可在 do 下按拓扑顺序传播期望，直接传播均值差以先消去共同截距，得到**模型真实 ATE（解析值）**；不是用更大随机样本代替真值。样本干预使用两个世界的共同外生噪声，按个体配对差 `d_i=Y_i(b)−Y_i(a)` 计算 `mean(d)` 和 `SE=s_d/sqrt(n)`，与独立两组样本 SE 不同。报告误差 `估计 ATE−真实 ATE`。

加性线性结果的个体处理效应可能恒定，此时估计误差和配对 SE 可为零；二元结果通常仍有 Monte Carlo 波动。共同噪声耦合是该 SCM 的实验设定，不能从现实观察数据中恢复个体潜在结果。

## 三个内置案例

所有案例都是程序生成；总体性质来自参数，不挑选随机样本保证效果。小样本可能不能呈现预期符号。

### A · 混杂因素

```text
U → X → Y
└─────→ Y
```

`U~Bernoulli(0.5)`，`P(X=1|U)=0.1+0.8U`，`Y=2X+6U+ε`，`ε~N(0,1)`。

`E[U|X=1]=0.9`，`E[U|X=0]=0.1`，所以总体朴素差为 `2+6×0.8=6.8`。在 U 内两组差都为 2；调整后效应和模型真实 ATE 都为 2。

### B · 碰撞变量

```text
A → C ← B
```

A 与 B 独立 `Bernoulli(0.5)`；`P(C=1|A,B)=0.05+0.45A+0.45B`。

总体 A/B 相关为 0；在 C=1 内，`P(A=1)=P(B=1)=0.725`、`P(A=B=1)=0.475`，所以条件相关约为 −0.254。选择碰撞变量引入非因果关联；`do(A)` 不改变 B，真实 ATE=0。

### C · 辛普森悖论

```text
G → X → Y
└─────→ Y
```

`G~Bernoulli(0.5)`，`P(X=1|G)=0.9−0.8G`，`Y=10G+2X+ε`。

每个 G 子群体中差都为 +2；汇总时，`E[G|X=1]=0.1`、`E[G|X=0]=0.9`，因此差为 `2+10×(0.1−0.9)=−6`。高基线子群在处理组的比例下降导致方向反转，真实 ATE 仍为 +2。界面显示组 n、两处理组 n/均值及汇总统计。

## JSON 模型与实验格式

模型 JSON（必须精确使用这些字段，拒绝未知或缺失字段）：

```json
{
  "schemaVersion": 1,
  "name": "线性示例",
  "variables": [
    {
      "id": "X",
      "label": "处理",
      "kind": "linear",
      "intercept": 0,
      "weights": {},
      "noiseStd": 1
    },
    {
      "id": "Y",
      "label": "结果",
      "kind": "linear",
      "intercept": 0,
      "weights": { "X": 2 },
      "noiseStd": 1
    }
  ]
}
```

`kind` 为 `linear` 或 `bernoulli`。ID 唯一，字母开头，后续为字母/数字/下划线，最多 24 字符，禁止原型保留名称；label/name 为 1–80 字符。最多 12 节点，截距/系数绝对值≤100，连续噪声标准差在 [0,100] 内。所有引用必须存在，图必须无环。

实验参数 JSON：

```json
{
  "format": "causallab-experiment-v1",
  "model": {
    "schemaVersion": 1,
    "name": "示例",
    "variables": [
      {
        "id": "X",
        "label": "处理",
        "kind": "linear",
        "intercept": 0,
        "weights": {},
        "noiseStd": 1
      },
      {
        "id": "Y",
        "label": "结果",
        "kind": "linear",
        "intercept": 0,
        "weights": { "X": 2 },
        "noiseStd": 1
      }
    ]
  },
  "settings": {
    "n": 10000,
    "seed": 42,
    "treatment": "X",
    "outcome": "Y",
    "group": "",
    "low": 0,
    "high": 1
  }
}
```

导入最多 64 KiB（按 UTF-8 字节检查），模型与实验分别选择对应导入类型。只导入模型时，界面设 n=10000、seed=42，前两个变量作为处理/结果；需重新选择适用的分析变量。实验导入保留全部设置。非法 JSON、循环、越界概率、非有限数字、资源超限均会拒绝。不支持用户代码或表达式执行。

分析结果 JSON 额外包含 `semantics`、`trueATE`、`observation` 和可空的 `intervention`；不作为参数文件导入。结果 CSV 是指标长表，`scope` 区分描述、观察、条件与干预；各行含 n/seed/真实 ATE，首个 metadata 行含完整模型/实验 JSON 和统计口径。文件为 UTF-8 BOM、CRLF，遵循 CSV 引号转义，对可能成为公式的文本单元格加单引号，数值负号保持数值。CSV 不导入；不导出逐行原始数据，可由实验参数重新生成。

## 限制与后续

仅支持小型 DAG、连续线性方程和二元仿射概率；无多类别、任意非线性、反馈环、缺失数据、测量误差、隐藏混杂建模、自动因果发现或现实数据导入。当前调整法不等于一般因果识别器，不支持任意条件控制。条件均值效应同质，不演示一般效应异质性带来的区间复杂性。极端系数链和数量级差距会放大浮点舍入，样本差可能丢失很小的效应；解析 ATE 单独传播差值以减小此问题。

计算在主线程有界运行，12 节点 / 20000 行上限下完成一次批量实验，不提供中途暂停；修改参数、清空和重复运行可用。图形 SVG 自动布局，密集 DAG 可能有边重叠。直方图各自缩放，不应直接比较不同图的柱高。

Windows / Linux 自动验证状态见 [VALIDATION.md](VALIDATION.md)。Firefox/WebKit、真实手机和用户电脑人工试用不等于 Chromium CI，未执行的事项会明确记录。后续可按实际需要加入 Worker、稳健标准误、独立样本干预比较；不扩展成通用推断框架。
