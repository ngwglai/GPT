# CausalLab v0.1：可复现的观察与干预教学实验室

本地交付已完成。此文件是待提交的 PR 描述；尚未创建远程 PR，推送因最新 main 既有全历史隐私检查失败而暂停。诊断与恢复条件见 VALIDATION.md。

## 功能

在独立 `projects/causallab/` 中实现中文 DAG 编辑、严格可序列化 SCM、连续线性/二元仿射概率、固定种子样本、描述统计、观察性均值差/OLS/父变量调整、条件筛选、配对 do 干预、解析真实 ATE、估计误差与三个参数化案例。支持模型/实验导入、模型/实验/分析 JSON 和分析 CSV 导出、桌面和窄屏布局。

计算与 React UI 分层，无后端、遥测或付费服务。依赖版本沿用仓库现有项目；没有修改其他项目的业务代码或依赖。新增独立 Linux/Windows CI 并接入 CI required，不部署。

## 实际本地测试

95 项 Vitest、10 项生产 Chromium E2E、ESLint、TypeScript、Vite 生产构建、npm 全依赖审计（0 已知漏洞）、根 26 项隐私回归通过。暂存区、提交说明及实际新增提交分别检查；结果见 VALIDATION.md。

数学测试覆盖连续混杂下真实 ATE=2、朴素偏差、调整、非后代保持、条件与干预区别、二元结果 ATE=0.5、多中介总效应、碰撞变量与辛普森反转；五个固定种子，每次 20000 样本。

## 验收方式

按 README 安装后执行 lint、typecheck、test、build 和 test:e2e；或运行本地预览，加载案例、编辑参数、生成、观察、do、导出实验、重新导入并验证结果复现。必须等待本 PR 最新 SHA 的项目跨平台检查、根隐私检查和 CI required 通过才合并。

## 限制与阻塞

仅支持 12 节点、20000 样本、64 KiB 导入；完全观测、独立噪声、小型仿射 SCM；OLS 采用同方差 SE，分层区间以经验权重固定；主线程有界批量计算。用户电脑、Firefox/WebKit 和真实手机未验收。

现有 origin/main 全历史存在 12 项 known-private-identity 命中，本项目未修改命中文件。没有更改安全规则、词表或历史；没有使用 no-verify。需先通过独立流程解决该隐私阻塞，然后才能推送、创建 PR、运行远程 CI 和合并。
